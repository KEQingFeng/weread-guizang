# 归藏 · 交接说明（1.2.0 · 2026-10-14）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、哪些已经验过、哪些还差。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁看 `架构与模块地图.md`。

一句话交接：**1.1.0 把阅读 AI 从「小 Agent」里拆成独立配置，小结改到阅读器右栏第三页签内联展示；外观氛围渐变改为预设+自定义；视频转笔记界面按学生使用习惯做了步骤条与可读性打磨。第二轮接着做了：顶端正中的「AI 导航」与内置浏览器（`ai-bot.cn` 与安娜的档案都能在软件内直接看）、便签改成 memos 两栏、推荐页只留六本，并把切页一致性（每屏同一块舞台）与小 Agent 的回话形状兼容收口。第三轮（1.2.0）做了：剪藏顶部改「手指圆钮读剪贴板 + 环形进度 + 解析已完成」、视频转笔记四处体验（长视频加载分页、进度条实时、刷新留「转写中」、停止点击即停）、思维导图放宽间距 + 双指缩放、便签富文本编辑并保留 Markdown 复制粘贴、微信书架远端封面 Referer 修复。** 版本号 1.1.0 → 1.2.0。**本轮未在本机打新安装包**（开发机是 Linux，没有 swift / hdiutil）；`安装包/` 里仍是 1.0.9 的 dmg / Windows zip。要出 1.2.0 的 dmg，在 Mac 上跑：

```bash
bash shell/build_macos.sh && bash shell/make_dmg.sh
```

`build_macos.sh` 会从 `ui_server.py` 的 `VERSION` 读出版本盖进 Info.plist；`make_dmg.sh` 再从 plist 取名。

## 1. 这一轮改了什么

### 更新内容

- **阅读 AI 独立配置**（`ai_*`）：设置里单独一栏；单独配了就各走各的，没配才沿用小 Agent。导图与流式小结都走 `ai_cfg()`（`agent_once(..., cfg=ai_cfg())`）。Key 回显只末四位；密码框白名单含 `aikey`。
- **阅读 AI 小结进右栏第三页签**：取消独立浮层；点「小结」后在 `.rdnotes` 第三栏加载，`.rdnotes.aiopen` 切换；可在当前页存为笔记 / 画导图。
- **氛围渐变可自定义**：六套预设 + 自定义色点与角度，与磨砂/模糊同一份 LOOK 落盘；默认色与旧色晕同色。
- **视频转笔记学生向布局**：步骤条、结果区标题、段落间距与书架可读性、空状态文案。

### 第二轮（UI 一致性 / AI 导航与内置浏览器 / 修复）

- **切页一致性**：`main` 的宽度收成一处 `--main-w:min(1440px,100%)`，撤掉按页另开宽度的
  两条口子，`html` 常驻 `scrollbar-gutter:stable`；视图常驻、只挪 `hidden`，交接动效第一次
  给足、回头客收一档。解决「前几屏正常、突然左右变动极大」。护栏 `check_pane_uniform.py`。
- **AI 导航 + 内置浏览器**：顶端正中「AI 导航」在归藏自己的 Chromium 系内核里开 `ai-bot.cn`；
  新增 `web_browse.py` 取回层（外站由本机取回、补 `<base>`、接跳转脚本再送进 iframe，
  绕开 `X-Frame-Options` / CSP）；安娜的档案那一栏也接了「内置浏览器」入口；下载仍自动入书架。
- **便签 memos 两栏**：左边随手记灵感、右边时间线看记录。
- **推荐页只六本**：数据切到 6、渲染不铺页头。
- **修复**：微信书架缺封面退到本地那口取一次；封面退路加 `keySet` 闸，没配 Key 不再空敲
  404（`f469d0b`）。小 Agent 认下几种「不标准回话形状」（整段 JSON / `message` 形 /
  SSE-despite-`stream:false`），不再把满屏答案判成断线（`a5de750`）。

### 第三轮（1.2.0：剪藏 / 视频转笔记 / 思维导图 / 便签 / 封面）

- **剪藏：手指圆钮 + 环形进度 + 解析已完成**（`28ecfc3`，R3-9）。顶栏撤掉常驻粘贴框与
  「解析正文」按钮，只留一颗带手指 SVG 的圆钮 `#cPick`；点一下 `navigator.clipboard.readText()`
  → `clipSync()` 填链接 → `clipRunAll('preview')` 自动解析。外圈 `r=33` 的 SVG 圆用
  `stroke-dashoffset` 做环：14s 慢慢走到 92%，收尾 `clipRingDone()` 在 .35s 内补满（完成正好
  一圈）。解析完用 sheet 弹「解析已完成」，文章已在下方列表。读不到剪贴板时走
  `clipPasteFallback()` 弹层手动粘，屏顶不设常驻输入框。配图 `docs/shots/clip.png` /
  `clip-ring.png`。
- **视频转笔记：长视频加载 latency**（`703c45f`，R3-1）。`video_note.load_transcript()` 增
  `offset` / `limit` / `with_text`：切片挪进读取层，`with_text=False` 不拼全文；
  `transcript.json` 按（大小, mtime）缓存解析结果，`_write_json` 落盘即失效。
  `ui_server.video_view` 改走这条路。
- **视频转笔记：进度条实时渲染**（`23bedc1`，R3-2）。`vidTick()` 改读日志对象 `.s`
  （`/api/log` 回 `[{t,s}]`，旧代码把对象喂正则永远不中）；新增 `runningAt` 只认本趟任务开工后
  的进度行；无进度行时先亮「正在准备」的不确定条。
- **视频转笔记：刷新保留「转写中」**（`23bedc1`，R3-7）。新增 `VID_PENDING_KEY` /
  `vidPendingSet` / `vidPendingGet` / `vidPendingClear`；`renderVideoShelf()` 在 running video
  时左栏顶部插 `.vtbook.pending`「转写中」行，刷新后仍在；`vidFinish()` 撤掉。
- **视频转笔记：停止点击即停**（`23bedc1`，R3-8）。`ui_server.stop_task()` 发完信号立刻回
  （旧代码最多干等 10 秒），收尾交后台 `_finish_stop`；`vidStop()` 先锁按钮回「正在停…」再发
  请求，`vidTools()` 任务翻面后复原。
- **思维导图：放宽间距 + 放大整体尺寸**（`c5a3297`，R3-3）。`mindmap.py` 节点间距与画布尺寸
  放宽，长文字节点不再互相压叠。
- **思维导图：双指触控缩放替代加减号**（`c82fafe`，R3-4）。`ui.html` 拆掉 `#mmZoomIn` /
  `#mmZoomOut`，新增 `mmZoomAt()`（绕手势中心缩放，手指按住的内容不跑）与 `mmZoomWire()`
  （触控板 ctrl+滚轮 + 真触屏两指捏合，单指滚动不抢），`.mmwrap` 关掉浏览器页面缩放；
  「适应」`#mmZoomFit` 仍在。
- **便签：富文本编辑 + 复制粘贴保留 Markdown**（`f7ebda5`，R3-5）。左栏 `textarea#fmNew`
  换成 `contenteditable` 富文本区 + 工具条 `#fmBar`（粗 / 斜 / 标题 / 列表 / 引用 / 行内码）；
  新增 `fmDraftMd` / `fmExec` / `fmWrapCode` / `fmAfterEdit` / `fmPh` / `fmBarState` /
  `fmSetHtml`；`wrGet(root)` 加可选参数，存盘用写作页同一把 Markdown 尺。复制
  `fmCopyHandler` 把 `text/plain` 换成 Markdown、粘贴 `fmPasteHandler` 用 `wrParse` 渲染；
  卡片加一颗「复制」`fmCopyMd` 导出整条 `m.md`。
- **微信书架：部分远端封面加载不出来**（`86488fd`，R3-6）。定位为界面从来路（外站）取图，
  微信 / QQ 图床看 Referer 回 403；正文图早有 `no-referrer`，封面这条漏了。新增
  `extCoverImg` / `coverSrc`：远端封面统一设 `referrerPolicy='no-referrer'`，协议相对地址补
  `https`；`shelfCard` 与详情页大图都改走它。

## 2. 还没做 / 已知风险

- **未打 1.2.0 DMG / Windows zip**：README 安装链接仍指向 1.0.9 包，避免链到不存在的文件。
- **内置浏览器是尽力版**：本机取回重送能绕开嵌入门槛，但不带登录态、不代理 WebSocket /
  流式媒体；要登录或过验证的站点（如安娜的档案下载页）仍走弹出窗口那条路。这是边界，不是没做完。
- **剪藏读剪贴板需要权限**：浏览器不放行 `navigator.clipboard.readText()` 时（例如从非
  `127.0.0.1` 的来路打开），界面退到 `clipPasteFallback()` 的手动粘贴弹层；这是有意的退路。
- 取书仍依赖微信读书 Canvas；对方改版可能失效。
- `/api/restart` 仍无鉴权（本机回环，与既有风险相同）。
- 超大单文件 `ui.html` / `ui_server.py` 未拆（故意不挪根目录模块）。

## 3. 怎么验收

1. 设置 → 阅读 AI：单独填地址/模型后，小结与导图不改小 Agent 三项。
2. 打开一书 → 右栏「小结」页签：结果在第三栏，不弹独立窗；可存笔记 / 画图。
3. 设置 → 外观：换氛围预设 / 自定义色点，刷新后仍在。
4. 视频转笔记：看得见三步提示与结果区标题；贴一个长视频链接，翻屏不卡、进度条实时走、
   刷新后左栏仍有「转写中」、点停止立刻回「正在停…」。
5. 点顶端正中「AI 导航」：在归藏自己的内置浏览器里打开 `ai-bot.cn`，点页面里的链接仍在
   这一屏里往下走；安娜的档案那一栏也有「内置浏览器」入口。
6. 便签那一格：左边用工具条敲一段富文本，右边时间线立刻看得到；复制出去是 Markdown，
   卡片上「复制」拿到的也是 Markdown。
7. 剪藏那一格：复制一条文章链接，点手指圆钮，外圈环走满后弹「解析已完成」，文章在下方列表。
8. 思维导图：节点不再挤压，触控板两指捏合 / 触摸屏双指捏合能绕手势中心缩放，没有加减号钮。
9. 推荐页：只有六本，六本上方没有任何文字。
10. 左侧逐格点过去：每一屏左右边一致，不横跳；在阅读器里选一段问小助手，几家上游的
    非标准回话形状也不该显示成「断线」。
11. 微信书架里取回的部分书封面（外站图床）能正常显示。
12. 关于 / 页顶版本为 1.2.0。
