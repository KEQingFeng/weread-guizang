# 归藏 · 交接说明（0.9.9 · 第二十九轮 · 2026-10-03）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 六条主链路 / §7 前端那几个反复踩到的事实）。

一句话交接：**这一轮把「取到内容之后」的那几屏当产品做，不是再挂一个小插件**——
视频与订阅各自长成了一台工具（有自己的路由、分页、筛子与导出），笔记里多了能编辑的
思维导图（四种形态）和一块画板（边看书边画，画进笔记）；MCP 从 32 个工具长到 45 个；
另外摊平了十来条只在真机上才暴露的显示与交互问题。版本号按约定仍是 `0.9.9`，
`.app` 与 `dmg` 这一轮**重打**了（见 §6）。

---

## 1. 这一轮改了什么

### 两个新模块（各管一类产物，都不碰通用解析器）

| 模块 | 它管的事 | 为什么单独一个文件 |
|---|---|---|
| `mindmap.py` | 可编辑思维导图：一份文档 = 一棵树 + 一组带关系词的边，存 `<书目录>/mindmap.json`。四种形态（括号 / 辐射 / 鱼骨 / 概念）的**坐标一律后端算完再交给前端画**，清洗与上限（400 节点 / 8 层 / 200 条边）也在这里 | 它要的是「一份能反复改、改完还能画出同一张图」的文档模型；`book_notes.py` 里那份导图是从大纲**现算**的只读 SVG，两者形状不同、寿命不同，硬塞进同一个文件迟早互相覆盖 |
| `board.py` | 画板：一块板 = `<书目录>/boards/<id>.json` 一份画布 JSON（fabric.js 序列化，**JSON 是真相，SVG / PNG 是导出物**）。五种纸面，一本书最多 200 块，尺寸与字节都有闸 | 画布内容是第三方库的对象树，本仓库不认识它也不需要认识；单独一个文件才能把「不解析、只限体积与条数、覆盖前留 `.prev`」这条边界写清楚 |

两者的产物都落在书自己的目录里，所以「复制这本书就带走它的笔记」这条老规矩没变；
也都**不在** `reset_book_output()` 的清掉重取清单里（`RESIDUE_DIRS` / `RESIDUE_FILES`），
用户画的和导的图不会因为「重取一次正文」被抹掉。

### 两屏长成工具

- **视频转笔记**不再是一条进度条：`/api/video` 有自己的 `mode=plan|books|transcript|status`
  与 `act=start|ffmpeg|stop|save_transcript|rebuild|export`，转写工作台带分页
  （界面 `VT_PAGE=240`，后端 `VIDEO_SEG_PAGE=1200`）、筛子、待存队列、撤销重做，
  导出五种字幕/文本格式（`exports/` 下的 srt / vtt / txt / md / json）。
- **订阅**是一台三栏阅读器：左栏按分组 / 标签 / 未读 / 收藏 / 稍后读组合筛，
  中栏条目列表走**定点更新**（`feSyncRow` 只补需要变的那几行，不整片重建），
  右栏正文可以「回抓一次全文」再入书架。刷新进度 900ms 轮询问的是「抓到哪了」，
  不是「该不该抓」；抓取期间用户点的已读 / 标签 / 删除由一把可重入锁护着不被覆盖。

### MCP：32 → 45 个工具（九类）

书架与状态 6 / 取书与账号 4 / 书与笔记 6 / 写回与导出 4 / 网页剪藏 1 / 订阅 8 /
视频 8 / 思维导图 3 / 画板 5。新增的写口都带同一条护栏：**只发改动的片段，
不许拿屏上那份当全书**（转写、导图、画板三个整本覆盖的接口各自验一次），
由 `tests/check_mcp_tools.py` 现读 `tools/list` 逐条走。

### 书架与阅读器

叠卡布局改成左右对称：当前这本的两侧各摊三张，都能看见都能点，
所以往左点翻回去、往右点翻过来，不再是「只有右边有书」。
本章大纲从 60 条放到 200 条，并在字号 / 行距变化后重量一遍。

### 修了的那批（根因都写在这，别只当 changelog 看）

| 现象 | 根因 | 落点 |
|---|---|---|
| 脑图换了一种排法，停手一秒半自己跳回括号图，而且跳回的结果被存进盘里（钮亮鱼骨、纸画括号） | 形态只存在界面的一份状态里，没写进文档；自动保存发出去的还是旧文档，后端按 `doc.form` 算回的布局把画面和 `mindmap.json` 一起拽回上一形态 | `ui.html` 的 `mmSetForm` 同时写 `MM.form` 与 `MM.doc.form`；`mmSave` 回调与撤销 / 重做之后一律以磁盘那份为准。断言在 `check_board_map_ui.py`：切鱼骨 → 越过自动保存 → 屏上、文档里、盘上三份一致 |
| 点不中一颗脑图节点、连线点不动 | 拖完松手时在 `mouseup` 里重画了一次，把那颗节点整块换掉，紧跟着的 `click` 就落不到节点上 | 没拖动就直接 return（`if (!r.moved) return;`），拖动过才写回坐标并让后端重算 |
| 黑纸上画深墨「画了跟没画一样」 | 原来只掰「还是默认那支深墨」的情况，用户自己挑过颜色（比如深红）就照样一片黑 | 按 sRGB 相对亮度判纸墨是不是一个调子，是就反过来并说一声 |
| 一张节点都没有时，对着整片白纸以为卡在加载 | 原来只在最底下写一行小字 | 一张摆在画布正中的卡，带两个能点的钮（从根开始 / 用这本书的笔记生成） |
| 「复制文字」开出一个空白弹框，里面什么都没有 | 开了一条没填内容的路径——这比失败更糟 | 复用长选复制那条路（剪贴板被拦时自己退到 textarea） |
| 订阅那几个弹框（新建分组 / 改源名 / 打标签 / 导 OPML）输不进字 | 抬 `readonly` 的那行写的是 `el.readonly`，DOM 上没有这个小写属性，挂上去的是没人读的字段；自检读的是同一个小写名，实现和检查一起瞎 | 改 `el.readOnly`；`tests/check_js_refs.py` 把这类拼错钉成硬失败 |
| 打勾之后那排批量钮从来没出现过 | 点勾调的是 `fePick`，这个函数根本没写出来，当场 `ReferenceError` | 补上；`check_js_refs.py` 的另一半就是查「调一个从没写出来的函数」 |
| 戴着筛子保存把整本转写改剩一段 | 界面只看得见筛出来的那几段，而写盘接口是整本覆盖——这是工作台最容易出的事故 | 存之前一定回后端取一次**无筛法的全量**，按 `id` 把待存改动合上去再写回；后端收到空列表直接拒写。只能在真机上验到磁盘，所以有了 `check_video_workbench.py` |
| 「待存 3 处」报数比实际多 | 新插一段本身就是一处待存，又往 `edits` 里记了一条，数成两处 | 新段只进队列，不重复计入 |
| 转完的那本书不进左栏 | 列表只认 `mode=books` 那份详情，stamp 变了不重拉 | 任务完成后重拉一次 |
| 导出之后「导 1」那盏灯要等下一次轮询才亮 | 灯看的是导出计数，导出返回后没立刻重画那一行 | 导出回来立刻刷 |
| 本章大纲找不到要的那一节 | 讲义体一章能有一百多个小标题，截断的部分在大纲里根本不存在 | `slice(0, 200)`；字号 / 行距变了要重量一遍，否则「在读」会指错节 |
| 正文里没随书带出来的图在页面上留一个透明的洞 | 只有「重写 `src` 后触发 `error`」这一种检查；缓存里的 404 不会再补发一次 `error` | 按是否重写 `src` 分开挂检查，未重写的当场判；坏了换成一句明说的话 |
| 一边打字一边往下翻，划词小条收掉、想法丢在半路 | 滚动即收起，没看指针还停没停在它上面、「记一笔」是否已拿到焦点 | 这两种情况不收 |
| 筛选框每敲一下攒一个观察器 | 「加载更多」每重画换新节点，旧 `IntersectionObserver` 还盯着已摘出文档的那颗 | 换节点前先 `disconnect`（`moreIO`） |

上一轮（0.9.9 补）那三条的根因仍然成立，一并留在 §5 的坑表里，不重复展开。

## 2. 这一轮**没有**碰的东西

- 取书主链（`export_precise.py` 的 Canvas Hook 与分章）、`book_notes.py` 那份
  **只读现算**的导图、EPUB/PDF 导出、云同步、阅读统计 —— 全部复用。
- `platform_compat.py` / `sync.py` / `login.py` / `shelf_add.py` 一行没改。
- `bootstrap.py` 的依赖门禁仍是五项（`playwright, genanki, pypdf, feedparser, yt_dlp`）：
  **ASR 不进默认依赖**，这条边界本轮特意没松。
- 没引入任何第三方服务的网络调用；画布库是随包的 `vendor/fabric.min.js`，**不连 CDN**。

## 3. 还没验过的（诚实清单）

- **画板只在无头 Chromium 里点过**：压感、双指缩放、Apple Pencil、真实触摸屏都没有；
  fabric 序列化出来的 JSON 换一个大版本能不能原样打开，没做矩阵。
- **脑图的 SVG 没有导回过任何外部思维导图编辑器**：只保证自己的 md / svg 出口
  和「在界面上重开还是那张图」；鱼骨图在超大文档上的可读性属于排版性质，没量化。
- **转写整本覆盖那两条护栏跑的是夹具转写**：真 Whisper 输出的字段差异
  （比如整段没有 `start`）没有专门一份用例覆盖。
- **取书续传的真机链路**照旧不在日常门禁里：`check_resume.py` 验纯逻辑，
  `jump_to_catalog_item` 真的把阅读器拽到那一章，要真书 + 真登录态手动跑。
- 视频真跑链路要 `GUIZANG_VIDEO_LIVE=1`；ffmpeg 真下载要 `GUIZANG_FFMPEG_LIVE=1`；
  剪藏真机走查要 `GUIZANG_CLIP_LINKS`；字幕准确度没做过质量评估。
- 知乎 / 小红书 / X 的解析随对方改版可能失效；订阅的夹具是自己铺的，
  真站点改版的风险同样存在。失效时如实报错，不改成静默失败。
- **未在真实 Windows 上端到端验证**（老问题，跨平台分支只有单测假跑）；
  `.app` 未签名未公证，首次打开要右键「打开」。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **26 项**：静态 13 + 真机 13），
   确认环境与基线；改到前端只用重启浏览器，`ui.html` 每次 GET 都重读。
2. 读 `docs/架构与模块地图.md` §3「六条主链路」和 §7 那几条前端事实——
   这是最该先建立的心智模型，尤其是「形态是文档的一部分」和「画布的真相是 JSON」。
3. 要动哪条通路，先读对应模块开头的「为什么单独一个文件」那一段，
   再读它在 §2 的那一行（职责 + 关键入口 + 上限常量）。动脑图 / 画板之前，
   先把 `mindmap.py` / `board.py` 顶部那几个 `MAX_*` 看完：裁了要报数、空列表不写盘，
   这两条是所有写口的共同规矩。

## 5. 已知的坑（都踩过，写下来省下一次）

| 现象 | 根因 | 处理 |
|---|---|---|
| 取书卡在中途再也走不动 | 续传位置取自阅读器「上次读到」，停在一个翻不出内容的死点；外层一遇 0 章就收工 | 一轮 0 章后改用目录钉到「最后写出项的下一项」；目录末项即收尾 |
| 按了钮弹出的小条「瞬间消失」 | 同步 show，同一次 click 继续冒泡到全局「点别处就收起」 | 错开一帧再 show（`setTimeout(…, 0)`），与划词同路 |
| 连点侧边栏整屏闪 | 同一 pane 上叠了多条从 `opacity:0` 起手的入场动画 | `slideAnim` WeakMap：正在进场就不重开 |
| 书架加载失败被说成「书架是空的」 | 空列表与失败共用一句文案 | `shelfErr` 分三态，失败给「再试一次」 |
| 脑图换形态自己跳回并把回跳存进盘里 | 形态只活在界面状态里，没进文档 | 形态是 `doc.form` 的一部分；存后与撤销 / 重做后以磁盘为准 |
| 弹框输不进字 / 批量钮从不出现 | `el.readonly` 这个不存在的小写属性；调了没写出来的 `fePick` | `check_js_refs.py` 两类都算硬失败 |
| 戴着筛子保存把整本改剩一段 | 界面只见筛出的段落，写盘是整本覆盖 | 存前取无筛法全量、按 `id` 合并；空列表拒写 |
| 订阅刷新回来 0 条 | 把整页 HTML 当 RSS（页脚 `<rdf:RDF>`） | 判据「根元素是 feed」，有回归用例 |
| 视频「几个分 P」不显示 | 字段名 `pages`/`count` vs `parts` | 按 `count` 报总数，用 plan 的地址对分 P |
| 转写设置按钮点开即关 | 按钮在弹层外，被全局收起监听关掉 | 补 `stopPropagation` |
| 视频书架空态不显示 | 空列表指纹 = 初值 = 空串 | 指纹带上条数 |
| 无头里断言读到动画起点（本轮测试陷阱） | grid 列宽过渡在无头里不推进，量到的宽度是 0，而 FAIL 没带数 | `flush()`＝两次 rAF + `getAnimations().finish()`，不够再 `settle` 兜底，并把量到的数带进诊断 |
| 装了新依赖但 app 里报 `ModuleNotFoundError` | 只改了 `requirements.txt`，漏了 `bootstrap.py` 门禁 | 两处一起改（`开发规范.md` §8 步骤 3） |
| 新后端模块 app 里一点就哑 | 漏了 `shell/build_macos.sh` 的 `APP_FILES` | 已加反向守卫：漏了直接 die（本轮 `board.py` / `mindmap.py` 就是这么进去的） |
| dmg 跑到桌面上去了 | `make_dmg.sh` 默认输出 `~/Desktop` | 用 `bash shell/make_dmg.sh 安装包` |

## 6. 版本与产物位置

- 版本号单一出处：`ui_server.py` 的 `VERSION`（`0.9.9`，本轮按约定不动）。
