# 归藏 · 交接说明（1.0.8 · 第三十八轮 · 2026-10-07）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 十二段主链路 / §7 前端那几个反复踩到的事实）。

一句话交接：**这一轮做两件事 —— 视频转写整体云化（砍掉本地引擎），以及给划线笔记加「勾选范围 → 导出 flomo 导入格式 CSV」。**
前半：按用户要求，转写不再支持本机部署 —— `mlx-whisper` / `faster-whisper` 两条本地引擎、
权重缓存、镜像回退，连同整个 `media_setup.py` 一起删掉，只剩云端一路（用户自己填兼容 OpenAI 的
`/audio/transcriptions` 地址与 Key）。设置里那张「引擎 + 语言」选单改成三格（接口地址 / API Key /
模型）加一个语言；`pick_engine()` 只认 `auto` / `cloud`，老配置里写着的 `mlx` / `faster` 不再静默
当云端用，而是当面报「本地转写已移除，去设置里填云端地址」。后半：划线笔记右栏每条带一个勾选框，
工具条上多一颗「导出 CSV」，勾好几条点它，出来的字节一比一对上 flomo 网页版导入模板（UTF-8 BOM
+ `content,created_at` 表头 + 通篇 CRLF + `YYYY-MM-DD HH:MM:SS`），文件落在「设置里选的导出文件夹」、
没选就退回数据目录的 `downloads/`，重名自动加序号、绝不覆盖。
门禁总数 54 → **55 项**（静态 25 → 26、真机 29 不变：删一套 `check_media_setup`（本地引擎那半条
没了），进两套 `check_asr_cloud`、`check_notes_csv`）。
版本号 1.0.7 → 1.0.8，**本轮构建了安装包**（`安装包/归藏-1.0.8.dmg`，见 §6）。

## 1. 这一轮改了什么

### 转写云化：本地引擎整条移除（`video_note.py` + `ui_server.py` + `ui.html` + `bootstrap.py`）

用户的口径是「只留云端、不支持本地部署、填地址与 Key 即用」。落到代码上是三件事：

- **引擎挑选只剩一条路**。`pick_engine(want, asr_cfg)` 从此只认 `auto` / `cloud`（两者等价，
  都走云端）；`mlx` / `faster` 以及老配置里可能残留的任何别的字面量，一律 `raise ValueError`
  且消息里带「移除」二字并指路到设置 —— 把「我要用大模型」悄悄换成别的，比报错更让人火大。
  没填地址时另报一句带「地址」+「设置」的人话，不让用户对着一个点了没反应的按钮猜。
- **配置面收成三格**。后端 `set_media_cfg()` 恒把 `asr_engine` 钉成 `cloud`，只收
  `url` / `key` / `model` / `lang` 四样（`None` = 保留，`""` = 清空）；`asr_cfg_view()` 回给界面的
  是 `{"engine":"cloud","lang","url","key_set","key_tail","model"}` —— **Key 永远只回末四位**，
  明文既不进 `state` 也不进日志。`available()` 里 `asr` 那一项只剩 `{"cloud": True,"engines":["cloud"]}`，
  那个 `setup` 字段（报本地引擎装没装）随 `media_setup.py` 一起没了。
  界面上那四格是 `#asrUrl` / `#asrKey`（`type=password`）/ `#asrModel` / `#asrLang`，
  保存时恒发 `engine:"cloud"`，Key 留空 = 不改。
- **地址补齐照旧**。`_transcriptions_url()` 把用户填的地址补成 `…/v1/audio/transcriptions`：
  `<host>` 补成 `…/v1/audio/transcriptions`，`<host>/v1` 补成 `…/audio/transcriptions`，已经是完整端点
  就原样用，非 `http(s)://` 开头直接报「地址要写成 http:// 或 https:// 开头」。

被删的东西（连带清干净，不留兼容分支）：`media_setup.py` 整个文件、`cleanup.py` 与
`shell/build_macos.sh` 的 `APP_FILES` 里的对应条目、`bootstrap.py` 的第五步（装转写引擎）——
bootstrap 从此是**四步**（venv → 依赖 → Chromium → ffmpeg），`--fast` 那条静态套件
`check_asr_cloud.py` 里的 W3 就是钉这个（标签必须统一成 `/4`，不许留半截的 `/5`）。

**边界没变的那几条**：`yt-dlp` 与 `ffmpeg` 仍在（前者随平台改版天天要更新，视频取不到时先
`.venv/bin/pip install -U yt-dlp`）；`bootstrap.py` 的依赖门禁仍是
`playwright, genanki, pypdf, feedparser, yt_dlp` 五项，**ASR 引擎从来不在默认依赖里，删掉后也不加回来**。

### 划线笔记导出 CSV（`flomo_notes.py` + `ui_server.py` + `ui.html`）

用户要的是「在编辑器里勾选要导出的部分，按 flomo 的文件格式导出成 CSV」。分三层：

- **格式层**（`flomo_notes.build_import_csv(rows)`）：UTF-8 BOM + 表头 `content,created_at` +
  **通篇 CRLF** + 时间 `YYYY-MM-DD HH:MM:SS`（空时间留空）。为什么连正文里的换行也要归一成 CRLF：
  `csv` 模块只按 `lineterminator` 收**行尾**，字段内部原有的 `\n` 会原样写进引号里，于是整份文件
  就混着 CRLF 与裸 LF。用户给的样例（`~/Downloads/flomo_import_sample (1).csv`）是通篇 CRLF，
  所以 `_crlf()` 先把正文的换行归一，落盘后整份文件行尾才真正一致（导入端不必去猜两种行尾）。
  逗号 / 引号 / 制表符的转义交给 `csv` 模块，不手搓。
- **落盘层**（`POST /api/notes_csv`）：收 `{title, items:[{text, at}]}`，滤掉空条目，**一条都没有直接
  拒绝写盘**（回「没有选中任何内容」）；有货就落 `export_target_dir()`（设置里选的导出文件夹，
  没选退回数据目录的 `downloads/`），文件名 `flomo导入-<书名>.csv`，重名走 `unique_dest()` 加序号。
  日志**只记条数与文件名，正文一个字不落** —— 划线是用户的私事。
- **接线层**（`ui.html`）：划线笔记那一屏右栏每条带勾选框，工具条上多一颗 `#nbCsv`「导出 CSV」。
  点它时若一个都没勾，浮字说「先勾选要导出的条目」；勾了就把 `nbPicked()` 走 `nbFlomoText()`
  （与「导入 flomo」webhook 那条路**同一份文案加工**：原文用「」包住、附书名与标签），POST 上去，
  成功后浮字挂「打开文件夹」（`openexports`）。所以从这里出去的和从 webhook 出去的，是同一个形状。

**为什么要有这条路**：网页直连 flomo 的 webhook 要 PRO，而导入 CSV 谁都能用 —— 想让笔记进 flomo
又没开会员的人走这里。

- 取书引擎、图片下载、阅读器正文、云同步（WebDAV / Microsoft Graph）没动。
- 上一轮（1.0.7）的安娜的档案那一路、`code_disk` 判新旧那一路没动；`NAV_ITEMS` 仍是十三格。
- 每本书的阅读计划（`readplan.py`）、画板 / 导图 / flomo 便签 / 写作平台 / 个人主界面的实现没动。
- MCP 工具数仍是 **56**（十一类）：新增的「导出 CSV」**刻意不进 MCP** —— 它是「在界面里勾选」的事，
  Agent 侧没有可代做的勾选动作；`video_capability` 报的那盏灯改了措辞，但工具名与入参没变。
  个数以 `tests/check_mcp_tools.py` 现读 `tools/list` 为准。
- 没有新增第三方依赖：`requirements.txt` 一个字没动（删东西不加东西）。

## 3. 还没验过的（诚实清单）

- **转写只填了地址、没真联调过具体厂商**：云端那条路按兼容 OpenAI 的 `/audio/transcriptions`
  发 multipart，**未对某一家（OpenAI / 硅基流动 / 各家自建）逐一跑过真音频**；地址填错或连不通时
  会如实报错、视频页那盏灯也会写清原因，但「这份转出来的字准不准」取决于用户选的那个模型，不保证。
- **CSV 只在 flomo 网页版的导入页对过字节格式**（BOM / 表头 / CRLF / 时间写法），**没有真拿一份
  导出件去 flomo 里点过一次「导入」**；也没验过超长正文（多行、带表格）在 flomo 那边的表现。
- **真账号那一段没走过**：安娜的档案下载要先登录，只在沙盒 + 本机夹具上端到端跑过；**没有在用户
  自己的真实账号上点过一次真下载** —— 这一条要用户本人验。
- **安娜的档案的站点事实按天过期**：可达域名、搜索参数、是否强制登录都是实测结论；对方改版会表现为
  「窗口里下不动」，不是归藏报错。`check_anna_download.py` 无头跑得绿只证明归藏自己那半条管道通。
- **`code_disk` 认的是 mtime + size**：内容变了而这两样都没变（极少，`touch -t` 之类做得到）就认不出来。
- **阅读计划的页数与真实「屏幕页」不是一个单位**（一页 = 1000 字），沿用上一轮的说法。
- **界面这几条真机套件只在 Chromium 上验过**；Safari 没实测。**Windows 分支没端到端跑过**
  （本机只有 macOS），安娜的档案那个窗口在 Windows 上还没起过一次。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **55 项**：静态 26 + 真机 29），确认环境与基线。
   改前端只需重启浏览器（`ui.html` 每次 GET 都重读）；**改后端必须换进程**——页顶横幅除了版本号
   还会看 `code_disk`，「改了后端没重启」瞒不住。
   **跑真机套件时别同时改 `ui.html`** —— 真机套件从磁盘现读，边跑边改会读到半份。
2. 读 `video_note.py` 的 `pick_engine()` / `video_note._transcriptions_url()` 与 `ui_server.py` 的
   `set_media_cfg()` / `asr_cfg_view()`。**转写配置只走这三格**：地址 / Key / 模型（外加语言），
   引擎恒 `cloud` 不许再加回本地那一支；新增「往外的连接」时先确认它跟用户填的地址是同一处。
3. 再碰「把界面上的东西导成文件」这类功能时，先分清它是**接口取书**还是**交给人手的窗口**还是
   **本地落盘**：落盘这类照 `flomo_notes.build_import_csv` 的形状走 —— 纯函数拼字节（可在静态门里
   一比一对字节），路由只负责选目录与去重，界面只负责收集勾选。别把「格式对不对」藏在路由里。

## 5. 已知的坑（都踩过，写下来省下一次）

| 症状 | 根因 | 解法 |
|---|---|---|
| 落盘的 CSV 里混着裸 LF | `csv` 模块只按 `lineterminator` 收行尾，字段内部原有的 `\n` 原样进引号 | 落盘前 `_crlf()` 把正文换行也归一成 CRLF；`check_notes_csv.py` F9b 钉住「整份通篇 CRLF」（本轮） |
| MCP 那句「云端转写已就绪」是假绿灯 | `available().asr.cloud` 只是「这条路在代码里可用」的能力位（云化后恒真），拿它当「配好了」 | 要报的是用户填没填地址：读 `v.asr.url`，没填就说没填（`video_capability()` 与状态摘要两处都改了，本轮） |
| bootstrap 的步骤标签半截对不上 | 删了第五步，标签还写着 `[1/5]…[3/5]`，末步却是 `[4/4]` | 标签统一成 `/4`；`check_asr_cloud.py` W3 加断言 `"/5]" not in 源码`（本轮） |
| 老配置写着 `mlx` 却当成云端跑了 | 引擎挑选静默改道 | `pick_engine()` 对非 `auto/cloud` 直接报「本地转写已移除」并指路设置（本轮） |
| 左侧导航少了新增那一格，界面却不报错 | 页面每次现读磁盘、名册装在进程里，本机跑的还是旧进程；而两个版本号一样，旧判定只比版本号所以无声 | 后端多报 `code_disk`，界面把「码不相等」也当过期；`check_swapbar.py` 1b 钉住（1.0.7） |
| 窗口能开，但站点一直打不开 / 一下就 513 | 对方 WAF 在 TLS 层挡机器请求：无头 Chromium 与 `urllib` 都被顶回来 | 有头窗口是正确性要求；代理显式挂给浏览器（`--proxy-server`），Chromium 不一定照系统设置走 |
| 嵌进界面那一屏是空白的 | 页面带 `X-Frame-Options: SAMEORIGIN` | 不做内嵌；做成「工具自己开窗口」 |
| 关键词递过去了却没搜 | 搜索参数名猜的是 `term` | 实测是 `q`；`search_url()` 里钉死并写了注释，别再改回去 |
| 一点下载整个窗口卡住 | 立即触发下载的页面永远不 fire `load`，`wait_until` 用默认值就干等 | 用 `wait_until="commit"`（这类导航只看提交，不看载入完） |
| 归藏自己的界面反而打不开了 | 起浏览器时继承了系统代理，`127.0.0.1` 被代理吃掉 | 该窗口对 localhost 走 `--no-proxy-server`；探代理那套显式给的优先、探不通的 socks 跳过 |
| 同名文件把已入库的那本盖了 | 站点同名条目多，直接写同名 | `save_as` 同名加时间戳；入库另按字节摘要去重，同一本下两次只入一次 |
| 「格式不认」那份文件不见了 | 转换失败顺手删原文件 | `ingest()` 一律留原文件并把原因写进 `pending`，用户点的那次下载不许被抹掉 |
| 鼠标顺着一列划过去，整栏都在跳 | 悬停展开动作行用的是「改高度」，把该行撑高、把后面每一行都推下去 | 悬停只改颜色 / 亮度，显隐用 `pointer-events` 不用高度；`check_hover_shift.py` 扫 CSSOM 拦下 |
| 切日 / 夜那一下全屏闪一下 | 每个组件各带各的补间时长，主题变量一跳，它们各按各的节奏从旧色补到新色，中间有「混色帧」 | 换肤那一帧给 `<html>` 挂 `.theme-switching`，一次性压平所有过渡；`check_theme.py` 掐中途采样点 |
| 窄栏里文字杵成一条竖线 | 按钮没 `nowrap`，一个字一个字换行 | 全站 `button { white-space: nowrap }`，要折行的章节标题单独开回来；`check_spec.py` 钉住 |
| 文字戳出边框、压进旁边那一栏 | `flex: none` 的元素带文字时用 max-content 宽、不会缩 | 定宽标签补 `min-width: 0` + `overflow: hidden`（加省略号 / 两行截断） |
| 滑杆一碰就从 26 跳到 24 | 同一个缺省值写在两处、数值还对不上 | 外观缺省值只留一处真相；`check_spec.py` 静态拦 |
| 手没动，页面自己换了一屏 | 窄屏 reflow 把另一格推到静止指针底下，浏览器补发合成的 `pointerover`，被当成真悬停 | 砍掉 hover 触发的切页，只留点击（1.0.6）；切页监听不再挂 `pointermove` 之外的东西 |
| 取书时找不到输出记录 | 右下角任务抽屉撤了 | 书卡封面进度条右侧那颗「详情」点开就是那份记录；任务数据（`tasks` / `showTaskLog`）没删 |
| 装好的 `.app` 一进某一屏就崩 | `build_macos.sh` 的 APP_FILES 写死了旧清单，新模块没进包 | 新模块补进 APP_FILES；脚本的反向护栏本来就该拦住这类漂移，但**要跑一次 build 才看得见** |
| 新入口对老用户凭空消失 | 导航名册改成后端存顺序后，老用户存的顺序表里没有新 id，被当「不认识」丢掉 | `nav_view()` 把存的顺序里缺的 id 补在末尾（1.0.5 那轮） |
| 点新功能只说「本机服务没在跑」，而服务活得好好的 | 界面把 404 与连不上揉成一句；真因是端口上挂着旧代码的进程 | `gzApi` 四类失败各说各的话 + 横幅写明两边版本 + `port_verdict` 判动作（1.0.3 那轮） |
| 手动跑一份真机套件，把用户正在用的实例接管了 | `need_base()` 不给参数就缺省挂 8770，而 8770 正是用户那台归藏 | `need_base()` 现在没地址**直接退出**并说清怎么指沙盒；真机套件一律走 `bash tests/run_all.sh`（1.0.3 那轮） |
| 界面里冒出密码框 | 第三方凭据想「顺手」在本机收 | 规则：第三方凭据能不碰就不碰；非要存只存令牌、绝不存密码。界面里没有密码输入是硬项（1.0.6 立，往后沿用） |
| 整轮门禁偶发一个红，单独跑必绿 | 撞的是负载下的时序 | 复现要看负载；固定摆出断言而不是靠运气重跑（本轮 `阅读器续读与大纲`、`脑图与画板` 各见过一次，单独跑与整轮重跑都绿） |
| 撤销点下去，那道线过一会儿又消失 | 存盘回执是「出发那一刻」的快照，`ntSave` 无条件拿它覆盖本地 doc | 每次 `ntTouch` 记 `NT.rev`；回执只在 `rev` 没动时才认（1.0.2/1.0.3 那轮） |
| flomo 重复导入出现「同一条两个 id」 | id 是 `sha1("时间\|正文")`，正文动一个字就成了另一条 | 存储里正文原样不动，标签与格式只在**交付时**清洗（1.0.1 那轮） |
| dmg 打完了在仓库里找不到 | `make_dmg.sh` 不传参数默认丢桌面 | `bash shell/make_dmg.sh 安装包`（`开发规范.md` §8 就是这么写的） |
| 新增 `const st` 直接语法错 | 同一函数作用域里 `st` 已被「语音识别」占用 | 换名；inline JS 门禁当场抓出来 |
| 文档里的门禁项数过期 | 加减套件时忘了同步 | 项数写在 `开发规范.md` §7 与本文 §4；改套件就一起改（本轮：静态 25→26、总 54→55） |
