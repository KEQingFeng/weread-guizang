# 归藏 · 交接说明（1.1.0 · 2026-10-13）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、哪些已经验过、哪些还差。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁看 `架构与模块地图.md`。

一句话交接：**1.1.0 把阅读 AI 从「小 Agent」里拆成独立配置，小结改到阅读器右栏第三页签内联展示；外观氛围渐变改为预设+自定义；视频转笔记界面按学生使用习惯做了步骤条与可读性打磨。第二轮接着做了：顶端正中的「AI 导航」与内置浏览器（`ai-bot.cn` 与安娜的档案都能在软件内直接看）、便签改成 memos 两栏、推荐页只留六本，并把切页一致性（每屏同一块舞台）与小 Agent 的回话形状兼容收口。** 版本号 1.0.9 → 1.1.0。**本轮未在本机打新安装包**（开发机是 Linux，没有 swift / hdiutil）；`安装包/` 里仍是 1.0.9 的 dmg / Windows zip。要出 1.1.0 的 dmg，在 Mac 上跑：

```bash
bash shell/build_macos.sh && bash shell/make_dmg.sh
```

`build_macos.sh` 会从 `ui_server.py` 的 `VERSION` 读出版本盖进 Info.plist；`make_dmg.sh` 再从 plist 取名。

## 1. 这一轮改了什么

### 更新内容

- **阅读 AI 独立配置**（`ai_*`）：设置里单独一栏；单独配了就各走各的，没配才沿用小 Agent。导图与流式小结都走 `ai_cfg()`（`agent_once(..., cfg=ai_cfg())`）。Key 回显只末四位；密码框白名单含 `aikey`。
- **阅读 AI 小结进右栏第三页签**：取消独立浮层；点「小结」后在 `.rdnotes` 第三栏加载，`.rdnotes.aiopen` 切换；可在当前页存为笔记 / 画导图。
- **氛围渐变可自定义**：六套预设 + 自定义色点与角度，与磨砂/模糊同一份 LOOK 落盘；默认色与旧色晕同色。
- **视频转笔记学生向布局**：步骤条、结果区标题、段落间距与书架可读性、空状态文案。

### 第二轮（UI 一致性 / AI 导航与内置浏览器 / 修复）

- **切页一致性**：`main` 的宽度收成一处 `--main-w:min(1440px,100%)`，撤掉按页另开宽度的
  两条口子，`html` 常驻 `scrollbar-gutter:stable`；视图常驻、只挪 `hidden`，交接动效第一次
  给足、回头客收一档。解决「前几屏正常、突然左右变动极大」。护栏 `check_pane_uniform.py`。
- **AI 导航 + 内置浏览器**：顶端正中「AI 导航」在归藏自己的 Chromium 系内核里开 `ai-bot.cn`；
  新增 `web_browse.py` 取回层（外站由本机取回、补 `<base>`、接跳转脚本再送进 iframe，
  绕开 `X-Frame-Options` / CSP）；安娜的档案那一栏也接了「内置浏览器」入口；下载仍自动入书架。
- **便签 memos 两栏**：左边随手记灵感、右边时间线看记录。
- **推荐页只六本**：数据切到 6、渲染不铺页头。
- **修复**：微信书架缺封面退到本地那口取一次；封面退路加 `keySet` 闸，没配 Key 不再空敲
  404（`f469d0b`）。小 Agent 认下几种「不标准回话形状」（整段 JSON / `message` 形 /
  SSE-despite-`stream:false`），不再把满屏答案判成断线（`a5de750`）。

## 2. 还没做 / 已知风险

- **未打 1.1.0 DMG / Windows zip**：README 安装链接仍指向 1.0.9 包，避免链到不存在的文件。
- **内置浏览器是尽力版**：本机取回重送能绕开嵌入门槛，但不带登录态、不代理 WebSocket /
  流式媒体；要登录或过验证的站点（如安娜的档案下载页）仍走弹出窗口那条路。这是边界，不是没做完。
- 取书仍依赖微信读书 Canvas；对方改版可能失效。
- `/api/restart` 仍无鉴权（本机回环，与既有风险相同）。
- 超大单文件 `ui.html` / `ui_server.py` 未拆（故意不挪根目录模块）。

## 3. 怎么验收

1. 设置 → 阅读 AI：单独填地址/模型后，小结与导图不改小 Agent 三项。
2. 打开一书 → 右栏「小结」页签：结果在第三栏，不弹独立窗；可存笔记 / 画图。
3. 设置 → 外观：换氛围预设 / 自定义色点，刷新后仍在。
4. 视频转笔记：看得见三步提示与结果区标题。
5. 点顶端正中「AI 导航」：在归藏自己的内置浏览器里打开 `ai-bot.cn`，点页面里的链接仍在
   这一屏里往下走；安娜的档案那一栏也有「内置浏览器」入口。
6. 便签那一格：左边能记一条灵感（输入即存），右边时间线立刻看得到。
7. 推荐页：只有六本，六本上方没有任何文字。
8. 左侧逐格点过去：每一屏左右边一致，不横跳；在阅读器里选一段问小助手，几家上游的
   非标准回话形状也不该显示成「断线」。
9. 关于 / 页顶版本为 1.1.0。
