# 归藏 · 交接说明（1.0.5 · 第三十三轮 · 2026-10-04）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 九条主链路 / §7 前端那几个反复踩到的事实）。

一句话交接：**这一轮是功能轮，三件大活——写作平台、个人主界面与两张热力图、左侧导航
重构；顺带把设置里的文案按 Google 开发者文档的口径重写了一遍。** 三件活各配了一组新
门禁（写作平台真机、导航真机、时长账静态、文案静态），门禁从 40 项涨到 44 项；还挖出
并修掉一个真打包 bug（`build_macos.sh` 的 APP_FILES 漏了本轮三个新模块，包出来会
`import activity` 失败）。最要紧的一条根因写在 §1 第一段：**界面会重排，重排会把另一颗
导航塞到你不动的指针底下，浏览器据此补发一个 `pointerover`，于是「悬停即切换」当场把
页面跳走**——这不是新功能的 bug，是新交互踩的旧坑。版本号 `1.0.3 → 1.0.5`，**本轮构建了
安装包**（`安装包/归藏-1.0.5.dmg`，见 §6）。

## 1. 这一轮改了什么

### 根因：重排喂给「悬停即切换」一个假的 pointerover

新的左侧导航是「鼠标走到哪一格就自动切到哪一屏」（见下面「左侧导航重构」）。但它第一版
监听的是 `pointerover`。问题出在这种情况：窗口变窄、或某个断点触发重排时，**原本不在指针
底下的那一格会被挤到指针底下**，浏览器据此补发一个 `pointerover`——用户手没动，导航却
跳了。真机上表现为「什么都没点，页面自己换了一屏」。

修法是把切换只挂在 `pointermove` 上：真实的手指/鼠标移动才会发它，重排补发的 `pointerover`
不算数。`ui.html` 里那段监听旁边留了一段 why 注释，`tests/check_nav.py` 里摆了一条可失败的
断言——**主动 dispatch 一个 `pointerover`，页面必须不切屏**。这条是本轮最容易再犯的坑：
以后谁要去掉那段注释、把 `pointermove` 改回 `pointerover`，门禁当场红。

### 写作平台（后端 `writer.py` 726 行 + 前端写作屏）

定位是「AI 辅助写作」，不是代笔：用户自己码字，卡住了选中/标注再让 AI 搭手。

- **一篇稿子 = 书库第七格里的一本书**：`书库/写作/write_<12hex>/`，`draft.md` 是唯一真源，
  `meta.json` 记标题/字数/`rev`/时间/已看过的灵感角度，`versions/` 放快照。由此它白捡了
  整套书库能力（导出、云同步的账目结构）而不用另起一套存储。
- **存盘带版本号**：`writer_save` 带 `rev` 时对不上就当面拒绝（回 `ok:false` + `conflict`），
  绝不拿旧内容覆盖新内容。快照每存 `REV_STEP_SNAP = 20` 次拍一份，`KEEP_VERSIONS = 30` 份封顶。
- **AI 三件套**：`cont` 按用户选的长度续写（`LENGTHS` = 一句 / 一段 / 提纲要点 / 一整节，
  **续写多少由用户自己挑**，流式）；`spark` 出灵感，**每次刷新给 3 个新角度**（`meta.json` 里
  记着已看过的角度，不重复推同一个）；`polish` 润色（`POLISH_TONES` 几种语气），只回
  `diff_blocks` 差异建议、逐块等用户接受，**不动原文**。
- **多格式导出 + 排版模板**：`kind` = `png` / `pdf` / `epub` / `md`，四套模板
  `TPL_LABELS` = 黑白简约 / 商务蓝 / 青翠 / 米白书简（可切风格），图上可带工具名与日期。
  导出全落到 `DOWNLOAD_DIR`，共用同一份 HTML——图片/PDF 走随包的 Chromium，EPUB 仍是标准库
  `zipfile`（本机没有 ebooklib/PIL/reportlab，也不许装 AGPL 的 ebooklib）。
- **素材只进提示词**：选中的上下文、笔记内容只发给用户自己填的那个兼容 OpenAI 接口，
  不写日志、不进回执。界面上那句「原文只进提示词」是明写出来的承诺（`check_writer_ui.py` 钉着）。

### 个人主界面 + 两张热力图（`person.py` 74 行 / `activity.py` 245 行）

- 左上角原来的「设置」入口换成了**个人主界面**：可本地上传头像（`person.sniff_image` 认
  PNG/JPEG/GIF/WEBP 魔数，8MB 上限）、改个人简介（`BIO_MAX=200`，名字 `NAME_MAX=40`）。
  头像存 `cache/avatar.bin`、资料存 `config.json`，**不进云同步、不进 git**。原「设置」入口
  挪到个人主界面最下方。
- **两张热力图**：今日学习时长 = 应用启动后在后台的累计运行时长；今日写作时长 = 写作屏里的
  停留时长。数据层在 `activity.py`：心跳一次最多记 `MAX_TICK = 300` 秒（浏览器冻结 / 合盖睡醒
  会报一个巨大间隔，不夹就是一根通天柱），单日封顶 `MAX_DAY = 12` 小时，缺的日子补 0 而不是
  跳过（跳一格整张图就错位），`KEEP_DAYS = 400`、`YEAR_WEEKS = 53`。
- 这里其实是**三本账**：微信读书官方时长、`readstat.json`、以及本轮新加的 `activity.json`，
  三本各记各的、互不覆盖。

### 左侧导航重构（名册由后端出，前端不再手抄）

- 导航那一排的图标、名册、分组改成**由 `/api/state` 生成**——`ui_server.NAV_ITEMS` 是唯一真源
  （12 项：7 个空间 + 5 个工具），页面不再自己抄一份。新增入口只需改后端那张表。`nav_view()`
  负责按用户存的顺序与显隐整理，**新入口补在末尾**（老用户更新后不会发现某一格凭空没了）。
- **长按拖拽排序**：`DRAG_HOLD = 400`ms 进拖拽态。**入口显隐**：设置里勾选显示哪些格子
  （`nav_hidden`）；「全隐藏」会被拒——全关掉等于把界面关没了。
- **两种侧边栏模式** `SIDEBAR_MODES = ("open", "edge")`：`open` 是默认摊开；`edge` 是鼠标往左
  边缘靠近才弹出（`PEEK_ZONE = 268`，果冻式弹出）。指针越过就收回。
- 切换用 `DWELL = 150`ms 的停留门槛，配合上面那条 `pointermove` 根因修法。

### 设置文案对齐 Google 开发者文档

`tests/check_copy.py`（静态）守这一条：散文里不许有语气词、波浪号尾巴（「好的~」）、感叹号、
emoji（唯一放行的是剪藏正文那条清洗正则——它得把别人的 emoji 滤掉）；设置那一段每条提示
都得是**完整句子、以句号收**；顺带钉住个人主界面最下方那颗「设置」入口还在。

### 打包 bug：`build_macos.sh` 的 APP_FILES 漏了三个新模块

`shell/build_macos.sh` 的 `APP_FILES` 是本轮之前写死的清单，`writer.py` / `activity.py` /
`person.py` 三个运行期模块没进包——装出来的 `.app` 一进写作屏 / 热力图就会 `import activity`
失败。已补进清单。脚本自己那条反向护栏（「根目录的 `*.py` 必须都在 APP_FILES 里」）本来就是
为这类漂移准备的，只是这一轮先手动发现、手动补上了。**教训**：新加运行期模块，改完代码要
回头确认它在打包清单里；门禁不跑 build，这一条只有打包那一步才暴露。

### 四处新增门禁（现在静态 22 + 真机 22，共 44 项）

| 套件 | 它守什么 | 为什么单开 |
|---|---|---|
| `tests/check_activity.py`（静态） | 时长账纯函数：心跳夹 300 秒、单日封顶 12 小时、缺日补 0、连续天数对「今天还没开始」宽容 | 纯函数不算盘不碰 HTTP，进静态段、`--fast` 也带上 |
| `tests/check_copy.py`（静态） | 界面文案：零语气词 / 零俏皮号 / 零 emoji / 设置提示成句 | 不联网不开浏览器就能把「AI 味」挡在门外 |
| `tests/check_nav.py`（真机） | 导航名册对表、长按拖拽换序、坞里勾显隐（全隐藏被拒）、侧边栏 open/edge 两种模式、指针靠左缘弹出、悬停即切换；**并断言 dispatch `pointerover` 不许切屏** | 名册唯一真源在后端、交互只在浏览器里点得出来 |
| `tests/check_writer_ui.py`（真机） | 稿列 / 正文 / 六件事 / 导出模板：建/存/版本冲突/改名/快照/回退/四种导出各走一遍；浏览器段验六颗动作钮各开一次坞、第一句落下就把稿子建出来、模板芯片没被图标钮压扁、界面上那句「原文只进提示词」 | 写作最要紧的不是「存得下」而是「不许悄悄覆盖」，这条只有真机点得出来 |

## 3. 还没验过的（诚实清单）

- **写作 AI 三件套没对具体厂商逐一联调**：本地按常见的 `/chat/completions` 返回结构解析，
  返回格式特殊的接口可能失败。
- **稿子导出走随包 Chromium / 标准库 EPUB**，没在多重环境（不同 Chromium 版本、不同
  阅读器）上验证成品渲染质量。
- **两张热力图的停靠口径没长时间核过对**：心跳是基于前台/后台判定的累计时长，长挂一夜、
  频繁切前后台这类极端情形只有短时实测，没有多日对账。
- **左侧导航的拖拽与边缘触发只在 Chromium 验过**；Safari 上 `pointermove` + 果冻过渡那套没实测。
- **隐藏入口的边界只对着沙盒验过**：全隐藏会被拒这一条是按设计走的，但没有在真装过 `.app`
  的机器上走一遍。
- **头像上传的格式识别只覆盖 PNG / JPEG / GIF / WEBP**；别的格式会被拒。
- **Windows 分支没端到端跑过**：本机只有 macOS。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **44 项**：静态 22 + 真机 22），确认环境与基线。
   改前端只需重启浏览器（`ui.html` 每次 GET 都重读）；**改后端必须换进程**（1.0.3 那轮的
   横幅就是为这件事存在的）。**跑真机套件时别同时改 `ui.html`——真机套件从磁盘现读
   `ui.html`，边跑边改会读到半份。**
2. 读 `ui_server.py` 的 `NAV_ITEMS` / `nav_view` 与 `ui.html` 那段 `pointermove` 监听的 why
   注释。新增导航入口只改后端那张表、不要再在页面里手抄一份；**切换逻辑只许挂 `pointermove`，
   不许改回 `pointerover`**。
3. 新增任何界面调用的 `/api/...`，先补后端路由再写前端；`tests/check_route_pair.py` 会在静态门
   里拦住反过来的做法。真机套件一律通过 `bash tests/run_all.sh` 跑（它起沙盒并把地址传进去）。

## 5. 已知的坑（都踩过，写下来省下一次）

| 症状 | 根因 | 解法 |
|---|---|---|
| 手没动，页面自己换了一屏 | 重排把另一颗导航塞到静止指针底下，浏览器补发 `pointerover`，「悬停即切换」当成真悬停 | 切换只挂 `pointermove`；`check_nav.py` 断言 dispatch `pointerover` 不切屏 |
| 装好的 `.app` 一进写作屏就崩 | `build_macos.sh` 的 APP_FILES 写死了旧清单，新模块没进包 | 把 `writer.py`/`activity.py`/`person.py` 补进 APP_FILES；脚本的反向护栏本来就该拦住这类漂移 |
| 新入口对老用户凭空消失 | 导航名册改成后端存顺序后，老用户存的顺序表里没有新 id，被当「不认识」丢掉 | `nav_view()` 把存的顺序里缺的 id 补在末尾 |
| 界面文案还是「好的~」「点这里试试！」 | 文案没有可失败的门禁，改一处漏一处 | `check_copy.py` 静态守：零语气词 / 零俏皮号 / 零 emoji / 提示成句 |
| 长按拖拽和「悬停即切换」互相打架 | 长按门槛与停留门槛在同一批指针事件上 | 长按 `DRAG_HOLD=400`、停留 `DWELL=150`，且切换只认 `pointermove` |
| 热力图上冒出一根通天柱 | 心跳间隔没夹：浏览器冻结、合盖睡醒会报一个巨大间隔 | `activity.py` 单次心跳夹 300 秒 |
| 热力图整张错位一格 | 缺的日子被跳过而不是补 0 | `activity.py` 缺日补 0 |
| 点新功能只说「本机服务没在跑」，而服务活得好好的 | 界面把 404 与连不上揉成一句；真因是端口上挂着旧代码的进程 | `gzApi` 四类失败各说各的话 + 横幅写明两边版本 + `port_verdict` 判动作（1.0.3 那轮） |
| 三处各算一份代码指纹，永远判成「不一致」 | Python / Node / Swift 三份哈希口径不同 | 统一 `sha1(整个 ui_server.py 字节)[:12]`；两套门禁逐项对（1.0.3 那轮） |
| 手动跑一份真机套件，把用户正在用的实例接管了 | `need_base()` 不给参数就缺省挂 8770，而 8770 正是用户那台归藏 | `need_base()` 现在没地址**直接退出**并说清怎么指沙盒；真机套件一律走 `bash tests/run_all.sh` |
| 整轮门禁偶发一个红，单独跑必绿 | 撞的是负载下的时序（防抖 + 回执覆盖 / 工具条晚一帧） | 复现要看负载；固定摆出断言而不是靠运气重跑 |
| 撤销点下去，那道线过一会儿又消失 | 存盘回执是「出发那一刻」的快照，`ntSave` 无条件拿它覆盖本地 doc | 每次 `ntTouch` 记 `NT.rev`；回执只在 `rev` 没动时才认；上一笔没回时新的一笔排队 |
| flomo 重复导入出现「同一条两个 id」 | id 是 `sha1("时间\|正文")`，正文动一个字就成了另一条 | 存储里正文原样不动，标签与格式只在**交付时**清洗 |
| AI 小结半路断线后，上一次成品被空文件顶掉 | 「流没跑完」被当成「答完了」，照样落盘 | 落盘只在拿到完整内容之后；半路失败保留旧结果并如实说这次没成 |
| 栏名「看哪些」竖成一列 | flex 行里放**裸文本节点**，后面还跟着几颗钮 → 文本被压到只剩十几像素 | 标题包一层 `span` 配 `nowrap` + `flex:none`，行加 `flex-wrap` |
| dmg 打完了在仓库里找不到 | `make_dmg.sh` 不传参数默认丢桌面 | `bash shell/make_dmg.sh 安装包`（`开发规范.md` §8 就是这么写的） |
| 新增 `const st` 直接语法错 | 同一函数作用域里 `st` 已被「语音识别」占用 | 换名；inline JS 门禁当场抓出来 |
| 文档里的门禁项数过期 | 加减套件时忘了同步 | 项数写在 `开发规范.md` §7 与本文 §4；改套件就一起改 |
