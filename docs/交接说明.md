# 归藏 · 交接说明（1.0.7 · 第三十六轮 + 第三十七轮 · 2026-10-07）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 十二段主链路 / §7 前端那几个反复踩到的事实）。

一句话交接：**这一轮换了一条取书的路，并修了一个「只在我机器上看得见」的界面 bug。**
前半：按用户要求把 Z-Library 整条通路砍干净（客户端、路由、搜书页右栏、设置项、三套测试
全部移除，搜书改回只有微信读书一栏），换成左侧导航最下面那一格「**安娜的档案**」——
归藏自己起一个**看得见的**浏览器窗口，用户在窗口里搜书、翻页、点下载，归藏在后头盯住
下载夹，把落进来的文件转成书收进本地书架。后半：用户报「左侧未渲染安娜的档案」，查下来
**渲染没有错，错在判新旧**——页面每次从磁盘现读，而导航名册装在进程内存里，本机跑着的
还是 1.0.6 那份进程，两个版本号当时看着一模一样，旧判定一声不吭。后端因此多报一份
**磁盘上的代码指纹**（`code_disk`），界面把它当过期，横幅与「换新后端」一键照旧解决。
门禁总数仍是 **54 项**（静态 26 → 25、真机 28 → 29：删三套 Z-Library 的，进三套安娜的档案的）。
版本号 1.0.6 → 1.0.7，**本轮构建了安装包**（`安装包/归藏-1.0.7.dmg`，见 §6）。

---

## 1. 这一轮改了什么

### 根因：页面从磁盘现读，名册装在进程里

`ui.html` 是每次 GET 现读的，而路由表、`NAV_ITEMS` 那十三格、`VERSION` 都是进程起来那刻
装进内存的。所以「磁盘上已经是新版、页面上少了新增那一格」不是渲染 bug，是**新旧两份代码
同时在跑**。旧判定只比版本字符串（`GZ.back !== GUIZANG_PAGE`），而 1.0.6 与 1.0.7 之间如果
没改版本号（本轮改前确实没改），它就判不出问题，横幅不出现，用户只看得到「那一格没了」。

修法分两层，都只做在自己那半：

- 后端 `/api/state` 除 `code`（进程里那份 `ui_server.py` 的指纹）外，多报 `code_disk`
  （**磁盘上那份**的指纹，按 mtime + size 缓存，不是每问重算；读不到文件时回空串——
  读不到就当没证据，绝不因此喊「你过期了」）。
- 界面把两者不等也算 stale：`GZ.drift = !!(GZ.code && GZ.disk && GZ.code !== GZ.disk)`，
  再 `GZ.stale = 版本不等 || GZ.drift`。`gzStale()` 给这一支单独一句话案：
  「本机跑着的后端比磁盘上那份旧（改过代码没重启）」——**不报两个一模一样的版本号说瞎话**，
  这是 `check_copy.py` / `check_route_pair.py` 一直在拦的那类「没有依据的断言」。
  换新后端仍走既有那颗按钮（`POST /api/restart`），不新加流程。

`tests/check_swapbar.py` 补了第 1b 条：版本号相等、磁盘指纹不等 → 横幅必须出现，
且文案说的是「改过代码没重启」。旧实现在这条下是**绿色通过**的，所以它现在是一枚真钉子。

### 安娜的档案（`anna_state.py` 446 行 + `anna_browser.py` 269 行 + 导航第十三格）

定位与 Z-Library 那版不同：**不是接口取书，是把窗口交给用户**。归藏不代抓那一页、
不代填表单、不碰它的 cookie；它只做「开窗、递一条搜书口令、接住下载、记账」。

- **为什么必须看得见**：2026-10-07 在本机用有头窗口实测过——对方的 WAF 在 TLS 层挡机器请求
  （无头 Chromium 与 `urllib` 都被 307→513 顶回来），而页面带 `X-Frame-Options: SAMEORIGIN`，
  iframe 一律空白。所以 `launch_persistent_context(..., headless=False)` **是正确性要求，
  不是噱头**；「嵌进归藏那一屏」这条路实测走不通，才做成窗口。
- **域名靠试**：`open_first_page()` 按候选域名一个个试到打开为止，试成了记回账本，
  下次从能用的那个开始。当天实测只有 `annas-archive.is` 有响应（`.gd` 给 502、
  `.org` / `.se` 连不上）——这类事实会过期，所以不硬只认一个域，设置那一栏留了填新域名的口。
- **搜书是递口令，不是代操作**：界面点「让窗口去搜」只往 `cache/anna_cmd.json` 写一条，
  窗口下一轮轮询读到再去导航。**参数名钉死是 `q`，不是 `term`**（当天实测：`term` 打不通）。
  窗口没开时口令照样存，界面如实说「打开窗口就会搜这个」。
- **接住下载 → 转成书**：`downloads_path` 指进 `cache/downloads/anna/`，`handle_download()`
  落盘后立刻 `anna_state.ingest()` 走 `book_import.import_book(book_id_prefix="anna",
  source="local")`——和用户自己拖文件进来是同一条路，所以阅读器、导出、定位文件一行不改，
  书库也**没新开一格**（`book_layout.PREFIX_OF` 里 `anna_ → local`）。
- **三道闸写在 `ingest()` 里**：格式白名单 `KEEP_EXT`（EPUB / PDF / TXT / Markdown，
  站点有时不给扩展名，所以再看文件头认 `%PDF` 与 `PK`）；按字节摘要去重（站点的近重复条目
  很多，同一本下两次不给造重复书）；超过 `book_import.MAX_BYTES` 或解析失败就**留着原文件**
  并把原因写进 `pending`——用户点的那一次下载不许被一句「没成功」抹掉。
- **凭据一个不碰**：登录态只存在 `cache/anna_profile/` 那个浏览器档案里，归藏不读它；
  账本 `cache/anna.json` 只有文件名、字节数与时间；日志（stdout 会被收进界面「查看详情」）
  只印文件名与字节数。设置 → 「清除本地数据」的清单里补了 `anna_profile` / `anna.json` /
  `anna_cmd.json` 三项。
- **窗口不许变成僵尸**：`HARD_LIVE_S = 4 小时`到点自己收摊，`_on_stop` 收尾；后端那边
  读的是账里的 `window` 字段（`opening` / `open` / `gone` / `failed`），四种各有各的话，
  「已经不在了」不说成「没在跑」。

### 砍掉 Z-Library（整条通路，不留兼容口）

`zlib_client.py`（421 行）、`zlib_login.py`（第三十五轮那个「跳网页自己登录」的窗口）、
`/api/zlib` 路由、搜书页右栏那半屏、三个设置项、`cache/zlib.json`、三套测试，
连同 `cleanup.py` 与 `APP_FILES` 里的条目一起删。界面里不出现旧字样，也不留「已停用」的
占位入口——用户要的是砍掉，不是藏起来。搜书那一屏回到只有微信读书一栏。

顺带说清第三十五轮那条经验为什么仍然算数：那一轮为了「不在归藏里放密码框」把登录改成
开网页窗口自己登、令牌自动接回，全仓不再有密码框（`check_swipe` 那类断言里
「界面不得有 `type=password`」是硬项）。1.0.7 虽然把那条通路删了，**「不碰用户密码」这条
口径留着**，并直接写进了 `开发规范.md` §6 的凭据规则。

### 依赖与打包

`requirements.txt` 与 `bootstrap.py` 的依赖门禁这一轮**没有改动**：`anna_state.py` 只用
标准库，窗口那条需要的是 `playwright`（本来就在依赖里）与设置里按需装的「浏览器组件」——
所以那颗「打开浏览器窗口」的按钮在组件没就位时会如实说先到设置里装好。
`shell/build_macos.sh` 的 `APP_FILES` 补了 `anna_state.py` / `anna_browser.py`、删了
`zlib_client.py` / `zlib_login.py`（脚本那条反向护栏——「根目录每个 `*.py` 必须都在清单里」
——本来就是为这类漂移准备的，改完必跑一次 build 才看得见）。

### 门禁：删三套、进三套（现在静态 25 + 真机 29，共 54 项）

| 套件 | 它守什么 | 为什么单开 |
|---|---|---|
| `tests/check_anna.py`（静态） | 账本只存名字与数字、下载夹路径不许用 `../` 穿出沙盒、同摘要不重复入库、不认的格式留原文件并写清原因、域名清洗与 `q` 参数 | 不带窗口就判得掉的四件事，全离线，`--fast` 也带上 |
| `tests/check_anna_ui.py`（真机） | 十三格里那一格在不在、搜书只剩一栏且不再出现旧字样、窗口四种状态的文案与按钮、补收端到端（落盘 → 收进书架 → 界面看得见 →「看这本」跳到那张卡）、清空记录只清账不动书、四档视口、零 console 报错 | 分栏与跳转只有真机点得出来 |
| `tests/check_anna_download.py`（真机） | 中间那半条管道：download 事件接住、`save_as` 落盘、同名加时间戳不覆盖、转成书且只入一次库 | 自己起本机夹具服务让 Chromium 真点三下；**它无头也能跑，因为不碰对方站点** |
| `tests/check_swapbar.py` 第 1b 条（真机） | 版本号相等、磁盘指纹不等时横幅必须出现且文案是「改过代码没重启」 | 旧实现这一条是绿的，所以它是本轮那枚真钉子 |

被删的是 `check_zlib.py` / `check_zlib_route.py`（静态两套）与 `check_zlib_ui.py`（真机一套）。

## 2. 这一轮**没有**碰的东西

- 取书引擎、图片下载、阅读器正文、云同步（WebDAV / Microsoft Graph）、转写流水线没动。
- 每本书的阅读计划（`readplan.py`）、画板 / 导图 / flomo 便签 / 写作平台 / 个人主界面
  （头像与两张热力图）的实现没动。
- MCP 工具数仍是 **56**（十一类）：安娜的档案这一路刻意**不进 MCP**——它是「人在窗口里点
  下载」的事，Agent 侧没有可代做的动作，硬加一个工具只会诱导出「让 AI 替你去下载」。
  个数以 `tests/check_mcp_tools.py` 现读 `tools/list` 为准。
- 没有新增第三方依赖，`requirements.txt` / `bootstrap.py` 都没碰。

## 3. 还没验过的（诚实清单）

- **真账号那一段没走过**：下载要先登录，本轮只在沙盒 + 本机夹具上端到端跑过
  （接住 → 落盘 → 转书 → 上架），窗口也确实开到过对方站点。
  **没有在用户自己的真实账号上点过一次真下载**——这一条要用户本人验。
- **站点事实按天过期**：可达域名、搜索参数、是否强制登录，都是 2026-10-07 一次实测的结论；
  对方改版会表现为「窗口里下不动」，不是归藏报错。
- **窗口必须看得见，所以门禁替不了它**：`check_anna_download.py` 无头跑得绿，只证明归藏
  自己那半条管道通，不证明能从那座站点点下东西。
- **`code_disk` 认的是 mtime + size**：内容变了而这两样都没变（极少，但脚本 `touch -t` 之类
  做得到）就认不出来。缓存是为了 2.6 秒一轮询不每问重算，这个取舍写在了代码注释里。
- **阅读计划的页数与真实「屏幕页」不是一个单位**（一页 = 1000 字），沿用上一轮的说法。
- **界面这几条真机套件只在 Chromium 上验过**；Safari 没实测。**Windows 分支没端到端跑过**
  （本机只有 macOS），安娜的档案那个窗口在 Windows 上还没起过一次。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **54 项**：静态 25 + 真机 29），确认环境与基线。
   改前端只需重启浏览器（`ui.html` 每次 GET 都重读）；**改后端必须换进程**——现在横幅除了
   版本号还会看 `code_disk`，所以「改了后端没重启」再也瞒不住。
   **跑真机套件时别同时改 `ui.html`——真机套件从磁盘现读，边跑边改会读到半份。**
2. 读 `ui_server.py` 的 `NAV_ITEMS`（十三格）/ `nav_view` 与 `ui.html` 里侧边栏那几段 why
   注释。新增导航入口只改后端那张表、**不要在页面里手抄一份**（本轮那个 bug 就是这个分工的
   反面教材：抄了也不会出现，出现的是旧进程里那份）；**切页只许认点击**，不要再挂 hover 触发。
3. 再碰「又一条取内容的通路」时，先分清它是**接口取书**还是**交给人手的窗口**：前者照
   `feed.py` / `video_note.py` 单开文件并尽量进 MCP，后者照 `anna_state.py` + `anna_browser.py`
   分成「本地账（可离线测）」与「窗口（只能人工验）」两半，别把验不了的那半伪装成验过了。

## 5. 已知的坑（都踩过，写下来省下一次）

| 症状 | 根因 | 解法 |
|---|---|---|
| 左侧导航少了新增那一格，界面却不报错 | 页面每次现读磁盘、名册装在进程里，本机跑的还是旧进程；而两个版本号一样，旧判定只比版本号所以无声 | 后端多报 `code_disk`，界面把「码不相等」也当过期；`check_swapbar.py` 1b 钉住（本轮） |
| 窗口能开，但站点一直打不开 / 一下就 513 | 对方 WAF 在 TLS 层挡机器请求：无头 Chromium 与 `urllib` 都被顶回来 | 有头窗口是正确性要求；代理显式挂给浏览器（`--proxy-server`），Chromium 不一定照系统设置走 |
| 嵌进界面那一屏是空白的 | 页面带 `X-Frame-Options: SAMEORIGIN` | 不做内嵌；做成「工具自己开窗口」 |
| 关键词递过去了却没搜 | 搜索参数名猜的是 `term` | 实测是 `q`；`search_url()` 里钉死并写了注释，别再改回去 |
| 一点下载整个窗口卡住 | 立即触发下载的页面永远不 fire `load`，`wait_until` 用默认值就干等 | 用 `wait_until="commit"`（这类导航只看提交，不看载入完） |
| 归藏自己的界面反而打不开了 | 起浏览器时继承了系统代理，`127.0.0.1` 被代理吃掉 | 该窗口对 localhost 走 `--no-proxy-server`；探代理那套显式给的优先、探不通的 socks 跳过 |
| 同名文件把已入库的那本盖了 | 站点同名条目多，直接写同名 | `save_as` 同名加时间戳；入库另按字节摘要去重，同一本下两次只入一次 |
| 「格式不认」那份文件不见了 | 转换失败顺手删原文件 | `ingest()` 一律留原文件并把原因写进 `pending`，用户点的那次下载不许被抹掉 |
| 鼠标顺着一列划过去，整栏都在跳 | 悬停展开动作行用的是「改高度」，把该行撑高、把后面每一行都推下去 | 悬停只改颜色 / 亮度，显隐用 `pointer-events` 不用高度；`check_hover_shift.py` 扫 CSSOM 拦下 |
| 切日 / 夜那一下全屏闪一下 | 每个组件各带各的补间时长，主题变量一跳，它们各按各的节奏从旧色补到新色，中间有「混色帧」 | 换肤那一帧给 `<html>` 挂 `.theme-switching`，一次性压平所有过渡；`check_theme.py` 掐中途采样点 |
| 窄栏里文字杵成一条竖线 | 按钮没 `nowrap`，一个字一个字换行 | 全站 `button { white-space: nowrap }`，要折行的章节标题单独开回来；`check_spec.py` 钉住 |
| 文字戳出边框、压进旁边那一栏 | `flex: none` 的元素带文字时用 max-content 宽、不会缩 | 定宽标签补 `min-width: 0` + `overflow: hidden`（加省略号 / 两行截断） |
| 滑杆一碰就从 26 跳到 24 | 同一个缺省值写在两处、数值还对不上 | 外观缺省值只留一处真相；`check_spec.py` 静态拦 |
| 手没动，页面自己换了一屏 | 窄屏 reflow 把另一格推到静止指针底下，浏览器补发合成的 `pointerover`，被当成真悬停 | 砍掉 hover 触发的切页，只留点击（1.0.6）；切页监听不再挂 `pointermove` 之外的东西 |
| 取书时找不到输出记录 | 右下角任务抽屉撤了 | 书卡封面进度条右侧那颗「详情」点开就是那份记录；任务数据（`tasks` / `showTaskLog`）没删 |
| 装好的 `.app` 一进某一屏就崩 | `build_macos.sh` 的 APP_FILES 写死了旧清单，新模块没进包 | 新模块补进 APP_FILES；脚本的反向护栏本来就该拦住这类漂移，但**要跑一次 build 才看得见** |
| 新入口对老用户凭空消失 | 导航名册改成后端存顺序后，老用户存的顺序表里没有新 id，被当「不认识」丢掉 | `nav_view()` 把存的顺序里缺的 id 补在末尾（1.0.5 那轮） |
| 点新功能只说「本机服务没在跑」，而服务活得好好的 | 界面把 404 与连不上揉成一句；真因是端口上挂着旧代码的进程 | `gzApi` 四类失败各说各的话 + 横幅写明两边版本 + `port_verdict` 判动作（1.0.3 那轮） |
| 手动跑一份真机套件，把用户正在用的实例接管了 | `need_base()` 不给参数就缺省挂 8770，而 8770 正是用户那台归藏 | `need_base()` 现在没地址**直接退出**并说清怎么指沙盒；真机套件一律走 `bash tests/run_all.sh`（1.0.3 那轮） |
| 界面里冒出密码框 | 第三方凭据想「顺手」在本机收 | 规则：第三方凭据能不碰就不碰；非要存只存令牌、绝不存密码。界面里没有密码输入是硬项（1.0.6 第三十五轮立，1.0.7 沿用） |
| 整轮门禁偶发一个红，单独跑必绿 | 撞的是负载下的时序 | 复现要看负载；固定摆出断言而不是靠运气重跑 |
| 撤销点下去，那道线过一会儿又消失 | 存盘回执是「出发那一刻」的快照，`ntSave` 无条件拿它覆盖本地 doc | 每次 `ntTouch` 记 `NT.rev`；回执只在 `rev` 没动时才认（1.0.2/1.0.3 那轮） |
| flomo 重复导入出现「同一条两个 id」 | id 是 `sha1("时间\|正文")`，正文动一个字就成了另一条 | 存储里正文原样不动，标签与格式只在**交付时**清洗（1.0.1 那轮） |
| dmg 打完了在仓库里找不到 | `make_dmg.sh` 不传参数默认丢桌面 | `bash shell/make_dmg.sh 安装包`（`开发规范.md` §8 就是这么写的） |
| 新增 `const st` 直接语法错 | 同一函数作用域里 `st` 已被「语音识别」占用 | 换名；inline JS 门禁当场抓出来 |
| 文档里的门禁项数过期 | 加减套件时忘了同步 | 项数写在 `开发规范.md` §7 与本文 §4；改套件就一起改（本轮：静态 26→25、真机 28→29） |
