# 归藏 · 交接说明（1.0.0 · 第三十轮 · 2026-10-04）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 六条主链路 / §7 前端那几个反复踩到的事实）。

一句话交接：**这一轮是「把它当一件成品收尾」**——把上一轮遗留的两处硬伤（后台没起服务时
画板与导图报底层连接错误、写想法小条被挤成竖排）从根因修掉；把「视频转笔记」那条线缺的
组件改成**安装时装引擎、进门后后台下模型**；给 RSS 那一屏换了与本产品同一套的控件语言；
新增「卸载组件 / 清除本地数据」；README 收成 1.0 的单语版并配了五张真机截图。
版本号 `0.9.9 → 1.0.0`，`.app` 与 `dmg` 重打（见 §6）。

## 1. 这一轮改了什么

### 两个新模块

| 模块 | 它管的事 | 为什么单独一个文件 |
|---|---|---|
| `media_setup.py` | 视频那条线的组件：挑引擎、装引擎、下转写模型、后台线程报进度 | 「引擎随安装装、模型进门后在后台下」这条分工与状态机自成一体，塞进 `video_note.py` 会让「怎么转写」和「怎么把组件弄到手」搅在一起 |
| `cleanup.py` | 维护那两刀：卸载组件 / 清除本地数据 | 删东西的代码最该独立、最该能被单独测试 —— 它的白名单与四条红线就是这个文件本身 |

### 服务没起时不再把底层错误甩给上层

`mcp/guizang-mcp.mjs` 的传输层重写：认 `runtime.json` 找真实端口（服务自己会往后挪端口）、
自己找 `.venv` 的解释器、服务没起就先把它拉起来，拉不起来才报人话。
配套 `platform_compat.py` 加了 `write_runtime` / `runtime_file`（服务绑到哪个口就写下来）。
`feed.py` 顶层的 `import feedparser` 改成按需取——少一个可选包不该让整条服务起不来。

### 「写想法 / 改想法」小条的排版

根因不在宽度，在**类名撞车**：`.row` 这个类名上面（设置面板那一行）带着 `padding:10px 12px`，
小条底下的 `.row` 一并继承，白吃掉 24px；七颗标签钮只好一个字一行地竖排下来。
修法：显式 `padding:0`，标签单独占一行并允许折行，钮 `nowrap`，小条加宽到 320。

### 笔记栏能纯键盘走了

`.ntrow` 一直是 `tabindex="0"`，但按什么键都没反应（空承诺）。这一轮给上：回车跳回正文那一句、
`E` 改想法（条目是「接着写」）、`Delete` 删除；删掉之后右下角挂一颗「撤销」——**不可逆的动作
给一次反悔，比弹确认框拦在前面更省事**。顺手把「记一笔」统一叫「写想法」，与行上那颗钮同词。

### 视频那条线的组件：装引擎与下模型分开

- `bootstrap.py` 从三步变五步：前三步（venv / 依赖 / Chromium）仍然失败即停；后两步
  （ffmpeg / 转写引擎）**尽力而为，失败不拦门**——取书、剪藏、订阅、阅读器都不需要它们。
- 转写模型（Apple 芯片 `large-v3-turbo` 约 1.6 GB，其它平台 `small` 约 460 MB）改成
  **进门之后在后台下**：`ui_server` 起来时若 `GUIZANG_AUTO_MEDIA=1`（只有壳会设）就起后台线程；
  视频页多一盏「转写模型」灯，显示「准备中 37%（已下 600MB）」，下完自动变绿。
- 直连 Hugging Face 拉不动时**自动换 `hf-mirror.com` 再试一遍**；用户自己设过 `HF_ENDPOINT` 就不动它。
- 首启页多一行「视频转写组件」，由壳真跑一句 python 问 `media_setup.engine_ready()` 得出。

### 订阅那一屏：换成同一套控件语言

它以前像「另一个产品挂上来的插件」：控件高度 20/22/24/26/28 五种、圆角 5/6/7/8/9 五种、
几处写死的灰。现在收成三档（正常钮 26 / 行内小钮 22 / 输入 28）、圆角对齐阅读器、
悬停与浅槽改用 `--surface-2` / `--paper-inset`，列表行改成与笔记栏同形的圆角卡。
左栏宽度 228 → **252**，与阅读器目录栏同一个数。

### 设置里多了「维护」

- **卸载组件**：venv（转写引擎在里面）、`cache/tools` 的 ffmpeg、转写模型权重、Chromium。
- **清除本地数据**：登录态、书架清单、设置、阅读时长、笔记索引、订阅条目、剪藏、封面、下载中间件。
- 两个都是**先试算再删**：把「删什么、多大、书库在哪」摊开给你看，点了才动手。
- **书一定不动**（`~/Documents/归藏` 是红线之一，另三条：数据目录本身、仓库根、书库里的文件）。

### README 收成 1.0 的单语版

`README.en.md` / `README.ja.md` 删除（只留中文）；原先散在「更新记录」里的十来个版本
归纳进「它可以做什么」；新增「它在细节上在意什么」（理念、痛点与设计取舍，全部能从代码里举证）；
安装段收成三步；`docs/shots/` 下五张真机截图（书架 / 阅读器 / 脑图 / 订阅 / 视频）——
**图里全是沙盒夹具的假数据**，不含任何真实书名、账号或本机路径。

## 2. 这一轮**没有**碰的东西

- 取书引擎（`export_precise.py`）、图片下载、EPUB / PDF 导出、云同步、MCP 的工具清单都没改。
- 阅读器正文的重排与分章逻辑没动（只动了右栏笔记与那一屏的少量样式）。
- 没有新增依赖：`media_setup.py` 与 `cleanup.py` 都只用标准库。

## 3. 还没验过的（诚实清单）

- **1.6 GB 的模型下载没有真跑过一遍。** 下载逻辑（镜像回退、缓存目录判定、进度百分比）
  是用桩测的，`tests/check_media_setup.py` 29 条断言覆盖了分支，但真正的
  `snapshot_download` 联网路径**只在真机上跑过一次「不下载」的判定**，没等到 1.6 GB 落地。
- **两个包没有在别人的机器上装过。** `.app` 与 `dmg` 只在本机自检通过；未签名未公证，
  首次打开要右键「打开」或 `xattr -dr com.apple.quarantine`。
- **Windows / Linux 未端到端验证**（老问题：跨平台分支只有单测里 mock 平台标志跑过）。
  `bootstrap.py` 的 ffmpeg 一步在非 macOS 上会明确跳过（自动下载只服务 macOS）。
- **「笔记编辑器」这一套在整轮门禁里偶发失败过一次**（三次整轮里出现一次，单独跑 5 次全绿）。
  最可能是小条/提示的进场动画还没走完就去断言（`elementFromPoint` 会从
  `visibility:hidden` 的元素上穿过去），已把那几条固定 `sleep` 改成条件等待并连绿两轮；
  **若它再出现，先看是哪一条断言挂了**——`bash tests/run_all.sh > /tmp/gate.txt` 里有名字。
- 语音转写的**准确率**没有系统评测过（只有单条流水线的端到端）。
- 「清除本地数据」删登录态之后要重新扫码；这条在 UI 上写了提示，但**没在真机上走完一遍
  「删掉 → 重开 → 重新扫码」**。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **29 项**：静态 15 + 真机 14），确认环境与基线；
   改前端只用重启浏览器，`ui.html` 每次 GET 都重读。
2. 读 `docs/架构与模块地图.md` §3「六条主链路」和 §7 那几条前端事实——
   尤其是「形态是文档的一部分」「画布的真相是 JSON」，以及这一轮新加的
   「引擎随安装装、模型进门后下」这条分工。
3. 要动哪条通路，先读对应模块开头的「为什么单独一个文件」那一段，再看同目录 `开发规范.md`。

## 5. 已知的坑（都踩过，写下来省下一次）

| 症状 | 根因 | 解法 |
|---|---|---|
| 小条里七颗标签钮各一个字一行 | `.selpop .selnote .row` 继承了设置面板那条 `.row{padding:10px 12px}`，白吃 24px | 显式 `padding:0`；标签行 `flex:1 0 100%` 且允许折行；钮 `nowrap` + `flex:none` |
| 栏名「看哪些」「范围」竖成一列 | flex 行里放**裸文本节点**，后面还跟着几颗钮 → 文本被压到只剩十几像素 | 标题包一层 `span` 配 `nowrap` + `flex:none`，行加 `flex-wrap`（放不下就把钮挪下一行） |
| 订阅清单里摘要一个字一行 | `.frow .acts` 是 `flex:none`（五颗钮不收缩），中栏一窄就把 `.bd` 压到几十像素 | `.frow` 允许换行 + `.bd{flex:1 1 220px}`；摘要两行截断（`-webkit-line-clamp:2`） |
| 塞进提示条里的按钮点不着 | `.whisper` 整条是 `pointer-events:none` | 动作态加 `.whisper.act{pointer-events:auto}`，子元素选择器用 `>`（别写成 `.wa` 那样会漏配） |
| 判「文字占了几行」判错 | `Range.getClientRects()` 会把 `text-overflow:ellipsis` 那个「…」也算一个 rect | 用高度 ÷ 行高来数行；探针要先自证抓得到真竖排 |
| 新增 `const st` 直接语法错 | 同一个函数作用域里 `st` 已被「语音识别」那一行占用 | 换名（`mst`）；inline JS 门禁会当场抓出来 |
| Python 里 `for x in A if c else B` 语法错 | 那不是合法的生成式写法 | 先算出列表再 for |
| 文档里的门禁项数过期 | 加减套件时忘了同步 | 项数写在 `开发规范.md` 与本文 §4；改套件就一起改 |
| 服务端口挪窝之后 MCP 找不着 | 服务会从默认端口往后找空位，而适配器只拿到「请它用的」那个数 | 服务绑到哪个口就把口写进 `runtime.json`，适配器认这个回执 |
