# 归藏 · 交接说明（0.9.9 补 · 2026-10-02）

这份文件给「接手这一轮改动的人」看：这一轮改了什么、根因是什么、哪些地方还差验证。
装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，谁调谁、模块边界看
`架构与模块地图.md`（§2 模块表 / §3 五条主链路）。

一句话交接：**这一轮不加新能力，只把三条已有的路修稳**——取书卡死、笔记栏按不动、
书架加载不出来 / 连点闪。版本号仍是 `0.9.9`（按约定补丁轮不动版本），
**安装包没有重打**（见 §6）。

## 1. 这一轮改了什么

### 三个 bug（都已定位到根因，都有门禁守着）

| 现象 | 根因 | 改动落在哪 |
|---|---|---|
| 取书取到一半就再也走不动（实测《你身体里的奥秘》卡在 84 / 223） | 外层一遇到「本轮没写出新章节」就收工；而续传位置来自阅读器自己的「上次读到」，那一轮它停在了一个再也翻不出内容的地方，重跑照样落在同一点 → 永久卡死 | `export_precise.py`：新增 `resume_catalog_index` / `load_catalog_ordered` / `jump_to_catalog_item`；`main()` 加 `recovering` 一轮缓冲；`run_session` 收 `resume_at` |
| 笔记栏里划线下的「写想法」点了没反应 | 那颗钮在 click 里**同步** show 小条，而这一下 click 还会继续冒泡到 `document` 上「点别处就把小条收掉」那条监听 —— 同一个事件里刚摊开就被自己收走 | `ui.html` 的 `ntRowAct` memo 分支：改成 `setTimeout(…, 0)` 错开一帧（与划词那条路一致） |
| 书架偶尔加载不出来；点快了整屏闪 | 两件事：① 拉失败被说成「书架是空的」；② 每点一下都给同一块 pane 新起一条从 `opacity:0` 起手的入场动画，几条叠在一起就闪 | `ui.html`：`shelfErr` + `notLoaded()` + 骨架 + 「再试一次」；`slideView` 加 `slideAnim`（WeakMap），同一 pane 只留一条动画 |

### 顺带的两处稳定化

- **`moreIO` 泄漏**：筛选框每敲一下都会重画书架，「加载更多」那颗钮每次都是新节点，
  旧 `IntersectionObserver` 还盯着已经摘出文档的那颗 → 一次重画攒一个。现在换节点前
  先 `disconnect`。（`revealIO` / `restIO` 早有收尾，只有它漏了。）
- **取书续传的语义**（值得单独记住的一条）：目录里的「缺」有一大半是**假缺**——
  标题没被正文单独画出来（跟正文粘在同一个块里），于是匹配不上、切不出章，
  可它的正文其实已经落在相邻那章里了。所以续传**不能**从「第一个缺项」重读
  （那会把已写出的几章整段塞进下一个缺章，是重复不是补缺），只能「接着往下读」：
  从**最后一个已写出项**的下一项继续。目录末项都写出来了就收尾，不再空转。

## 2. 这一轮**没有**碰的东西

- 四个内容入口模块（`web_parse.py` / `feed.py` / `video_note.py` / `ffmpeg_tool.py`）一行没改。
- 阅读器、笔记系统的存储、导出（EPUB/PDF）、云同步、统计 —— 全部复用，没有新增能力。
- 微信读书侧的接口调用与登录态处理没变；MCP 工具集没变（仍 32 个）。
- `ui_server.py` 一行没改（所以版本号也没动）。

也就是说：**0.9.9 能干的，0.9.9 补照样能干**；这一轮只在「已有的路稳不稳」上加厚。

## 3. 还没验过的（诚实清单）

这一节照实写，别当成「都验过了」。

- **取书续传的真机链路没有进日常门禁**：`tests/check_resume.py` 验的是纯逻辑
  （前沿语义、目录顺序、接口在位）；`jump_to_catalog_item` 真的点到目录第 N 项、
  真的把阅读器拽到那一章，这一段要真书 + 真登录态。**动到 `jump_to_catalog_item`
  或 `resume_catalog_index` 的行为，必须找一本卡过的书手动跑一次。**
- **「写想法」的真鼠标走查只在 Chromium 无头里跑过**：它复现的是事件冒泡这一层，
  真机上如果还有别的差异（合成点击、触摸），门禁覆盖不到。
- **`slideAnim` 的「连点不闪」是逻辑保证 + 无头走查**：没做过「每秒点 N 下」的量化
  对照（不像 0.9.8 那样量过布局次数与主线程任务）。
- 0.9.9 留下的其余未验项照旧：视频真跑链路要 `GUIZANG_VIDEO_LIVE=1`；字幕准确度没
  做过质量评估；知乎 / 小红书 / X 的解析随对方改版可能失效；剪藏真机走查要
  `GUIZANG_CLIP_LINKS`；ffmpeg 真下载要 `GUIZANG_FFMPEG_LIVE=1`；`yt-dlp` 会随平台
  改版漂（失败先 `.venv/bin/pip install -U yt-dlp`）；订阅的 UI 只覆盖到「两屏能开、
  元素不溢出」；**未在真实 Windows 上端到端验证**（老问题，跨平台分支只有单测假跑）。

## 5. 已知的坑（都踩过，写下来省下一次）

| 现象 | 根因 | 处理 |
|---|---|---|
| 取书卡在中途再也走不动 | 续传位置取自阅读器「上次读到」，停在一个翻不出内容的死点；外层一遇 0 章就收工 | 一轮 0 章后改用目录钉到「最后写出项的下一项」；目录末项即收尾 |
| 按了钮弹出的小条「瞬间消失」 | 同步 show，同一次 click 继续冒泡到全局「点别处就收起」 | 错开一帧再 show（`setTimeout(…, 0)`），与划词同路 |
| 连点侧边栏整屏闪 | 同一 pane 上叠了多条从 `opacity:0` 起手的入场动画 | `slideAnim` WeakMap：正在进场就不重开 |
| 书架加载失败被说成「书架是空的」 | 空列表与失败共用一句文案 | `shelfErr` 分三态，失败给「再试一次」 |
| 筛选框每敲一下攒一个观察器 | 「加载更多」每重画换新节点，旧 observer 没人收 | 换节点前 `disconnect`（`moreIO`） |
| 订阅刷新回来 0 条 | 把整页 HTML 当 RSS（页脚 `<rdf:RDF>`） | 判据「根元素是 feed」，有回归用例 |
| 视频「几个分 P」不显示 | 字段名 `pages`/`count` vs `parts` | 按 `count` 报总数，用 plan 的地址对分 P |
| 传写设置按钮点开即关 | 按钮在弹层外，被全局收起监听关掉 | 补 `stopPropagation` |
| 视频书架空态不显示 | 空列表指纹 = 初值 = 空串 | 指纹带上条数 |
| 装了新依赖但 app 里报 `ModuleNotFoundError` | 只改了 `requirements.txt`，漏了 `bootstrap.py` 门禁 | 两处一起改（`开发规范.md` §8 步骤 3） |
| 新后端模块 app 里一点就哑 | 漏了 `shell/build_macos.sh` 的 `APP_FILES` | 已加反向守卫：漏了直接 die |
| dmg 跑到桌面上去了 | `make_dmg.sh` 默认输出 `~/Desktop` | 用 `bash shell/make_dmg.sh 安装包` |
