# 归藏 · 交接说明（0.9.9）

这份文件给「接手这一轮改动的人」看：0.9.9 加了什么、每个新模块的边界在哪、
哪些地方还差验证。装与跑看 `部署说明.md`，改代码的规矩看 `开发规范.md`，
谁调谁看 `架构与模块地图.md`。

一句话交接：**归藏从「微信读书导出器」变成了「本地书库的前门」**——
取书、剪藏、订阅、视频四条路都把内容落成同一形状的书，后面阅读、笔记、
导出、MCP 一视同仁。这一轮的全部新代码都是围绕「多开三条进入口」这件事。

---

## 1. 这一轮加了什么

### 三条新的内容入口

| 入口 | 模块 | 入口长什么样 | 落成什么 |
|---|---|---|---|
| 平台帖子剪藏 | `web_parse.py`（+ 既有 `clip_article.py`） | 贴知乎 / 小红书 / X / 公众号链接 | 一本 `clip_<名>_<串>` 书 |
| RSS 订阅 | `feed.py` | 贴一个网址（站点首页也行） | 一本 `feed_<名>_<串>` 书（按条入库） |
| 视频转笔记 | `video_note.py` + `ffmpeg_tool.py` | 贴 B 站 / YouTube 链接 | 一本 `video_<名>_<串>` 书 + `notes.md` / `mindmap.svg` |

### 配套改动

- **MCP 适配器从 20 个工具扩到 32 个**：新增剪藏 1、订阅 8、视频 3。
  分组与约束见 `架构与模块地图.md` §8。
- **界面新增两屏**：「订阅」「视频转笔记」，以及对应设置项（转写引擎、语言、
  ffmpeg 状态）。
- **依赖**：`feedparser`、`yt-dlp` 进了默认依赖（`requirements.txt` +
  `bootstrap.py` 依赖门禁）。ASR 引擎**故意不进**默认依赖，按需装。
- **数据**：新增 `cache/feed.json`（订阅存储）与 `cache/tools/`（按需下载的
  static ffmpeg）。
- **打包清单补漏 + 加守卫**：四个新模块一开始漏出了
  `shell/build_macos.sh` 的 `APP_FILES`，导致 .app 里缺它们（源码跑没事，
  装成 app 一用订阅/视频就哑）。现已补进清单，并给打包脚本加了
  「根目录每个 .py 都得在清单里，否则 die」的反向守卫。

### 这一轮修掉的四个 bug（都写进了 README 更新记录）

1. 订阅源判定误把整页 HTML 当 RSS（页脚夹 `<rdf:RDF>` 授权声明）。
2. 视频认链接时「几个分 P」的提示从不显示（`pages`/`count` vs `parts`）。
3. 视频「转写设置」按钮点开即关（弹层外按钮被全局收起监听关掉）。
4. 视频书架空态从不显示（空列表指纹 = 初值 = 空串）。

前三个是「字段名/事件冒泡」类的静默失配，第四个是「指纹判变化」的经典陷阱
——后两个已经写进 `开发规范.md` §4 当规矩。

## 2. 四个新模块的边界

### `web_parse.py`（知乎 / 小红书 / X）

- **管**：把这三个站的帖子正文抽出来，返回结构与 `clip_article._extract_once` 同形。
- **不管**：公众号等其他站点（走 `clip_article.py` 的通用解析器）；
  「一次一页」的假设没变，不做批量语义。
- **为什么单独**：一站一种取法（X 走 syndication 公开接口、小红书读
  `window.__INITIAL_STATE__`、知乎按未登录范围取），塞进通用解析器会改坏所有站点。
- **失效时先看哪**：`_zhihu` / `_xhs` / `_x` 三段各自的注释写了「现状」。
  某家改版失效，只动那一段；**别留一个看着正常、其实永远抛错的空壳**。
- **红线**：不做登录态绕过（也就不用上传用户 cookie）。未登录拿到验证页 → 如实报错。

### `feed.py`（RSS / Atom / JSON Feed）

- **管**：发现源 → 抓取（条件请求 ETag / Last-Modified）→ 解析 → 条目去重 →
  单条入书架。存储 `cache/feed.json`。
- **不管**：已读/未读与账号侧双向同步、后台定时轮询（只在被调用时刷新）、
  云同步（feed.json 不参与）。
- **判据**：订阅源只认「根元素就是 feed」——feed 的根元素之前不先出现
  `<!doctype` / `<html`。这条是 0.9.9 修 bug 换来的，有回归用例守着。
- **入库策略**：全文够长直接用，只有摘要才回源抓正文；同一 entry 不重复入库。
- **无后台线程**：进程退出即停，符合「不建常驻」的项目约定。

### `video_note.py`（视频转笔记）

- **管**：一条链接 → 音频 → 转写 → LLM 摘要 / 知识笔记 / 思维导图 → 一本书。
- **不管**：B 站 / YouTube 以外的站；LLM 配置（三件套由调用方取好、经
  `GUIZANG_VIDEO_OPTS` 传进来，**这个模块不 import `ui_server`**）。
- **只转点的那一 P**：认链接时列分 P，只把选中那一 P 交给 yt-dlp。
- **音频只落临时目录，转完即删**。
- **AI 缺席不算失败**：转写照存、书照进，结果里带 `ai_error` 说明原因。
- **可换的三处**：`probe_meta` / `download_audio` / `transcribe` / `llm_chat`
  是模块级函数，自测套件靠换掉它们做到不联网、不下模型。
- **pipeline 阶段键**（固定英文，界面按此分组）：
  `plan → download → asr → summary → note → mindmap → save`。

### `ffmpeg_tool.py`（按需 ffmpeg）

- **管**：把 static ffmpeg/ffprobe 下到数据目录（`cache/tools/`），不碰系统、
  不依赖 Homebrew。
- **不管**：系统里已有 ffmpeg 时它复用，不重复下。
- **「装上了没有」只认一个证据**：把二进制真跑一次，听到 `ffmpeg version` 那行。
  HTTP 200、zip 解开不报错都不算数（半截下载、运营商提示页、错架构都能骗过前者）。

## 3. 这一轮**没有**碰的东西

- 取书引擎（`export_precise.py` / `download_images.py`）一行没改。
- 阅读器、笔记系统、导出（EPUB/PDF）、云同步、统计——本轮全部复用，没有新增能力。
- 微信读书侧的接口调用与登录态处理没变。

也就是说：**0.9.8 能干的，0.9.9 照样能干**；这一轮只在「内容怎么进来」这一层加宽。

## 4. 还没验过的（诚实清单）

这一节照实写，别当成「都验过了」。

- **视频真跑链路没有进日常门禁**：`tests/check_video_note.py` 默认跑的是离线夹具
  （换掉下载/转写/LLM 三个函数）。真下载 + 真转写要 `GUIZANG_VIDEO_LIVE=1` 才开。
  改到 `download_audio` / `transcribe` 这两段，必须手动跑一次真链路。
- **字幕准确度没做质量评估**：转写用通用 Whisper，专有名词 / 多人对话 / 强口音
  不保证。没有做过任何量化评测，`README` 里也只是如实提醒。
- **平台的解析随时可能失效**：知乎 / 小红书 / X 依赖对方「现在」怎么发页面。
  有离线夹具用固定 HTML 守着解析逻辑，但夹具不能预测线上改版。
- **剪藏真机走查默认跳过**：`tests/check_clip_live.py` 要 `GUIZANG_CLIP_LINKS`
  备好链接表才跑（公众号链接会过期，不宜入库）。
- **ffmpeg 真下载只在开了开关时跑**：`GUIZANG_FFMPEG_LIVE=1`（离线用夹具）。
  真实的下载源（martin-riedl.de / evermeet.cx）改版会让它失效。
- **`yt-dlp` 会随平台改版漂**：这类工具天生要常更；失败时先
  `.venv/bin/pip install -U yt-dlp`。
- **订阅的 UI 只覆盖到「两屏能开、元素不溢出、分 P 卡片」**：
  `tests/check_media_views.py` 是浏览器套件，覆盖的是呈现，不是每种订阅源的抓取结果。
- **未在真实 Windows 上端到端验证**（老问题，跨平台分支只有单测假跑）。

## 5. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿，确认环境与基线。
2. 读 `docs/架构与模块地图.md` §3「五条主链路」——这是这一轮最该先建立的心智模型。
3. 要动哪条通路，先读对应模块开头的「为什么单独一个文件」那一段，
   再读该模块在 `架构与模块地图.md` §2 的那一行（职责 + 关键入口）。

## 6. 已知的坑（都踩过，写下来省下一次）

| 现象 | 根因 | 处理 |
|---|---|---|
| 订阅刷新回来 0 条 | 把整页 HTML 当 RSS（页脚 `<rdf:RDF>`） | 判据「根元素是 feed」，有回归用例 |
| 视频「几个分 P」不显示 | 字段名 `pages`/`count` vs `parts` | 按 `count` 报总数，用 plan 的地址对分 P |
| 传写设置按钮点开即关 | 按钮在弹层外，被全局收起监听关掉 | 补 `stopPropagation` |
| 视频书架空态不显示 | 空列表指纹 = 初值 = 空串 | 指纹带上条数 |
| 装了新依赖但 app 里报 `ModuleNotFoundError` | 只改了 `requirements.txt`，漏了 `bootstrap.py` 门禁 | 两处一起改（`开发规范.md` §8 步骤 3） |
| 新后端模块 app 里一点就哑 | 漏了 `shell/build_macos.sh` 的 `APP_FILES` | 0.9.9 已加反向守卫：漏了直接 die，不用记得补 |
| dmg 跑到桌面上去了 | `make_dmg.sh` 默认输出 `~/Desktop` | 用 `bash shell/make_dmg.sh 安装包` |
