## 1. 这一轮改了什么

### 根因：悬停改的是「占位高度」，于是它顶动了整栏

视频转写行与章节行都有一排动作钮（`.nacts`），平时收着、悬停时展开。第一版是用
`max-height` 从 0 撑到 30px 来展开的，而这些行是**在正常文档流里的**——展开自己那一行
的动作行，就等于把它自己撑高，后面的每一行都被顺次推下去。真机上表现为「鼠标顺着列表
往下划，整栏都在抖」，与其他按钮那一排的交互也对不齐。

修法：悬停只改颜色与亮度，**不碰任何占位尺寸**；收着的动作行用 `pointer-events` 控制
可点性，不用高度控制显隐。`tests/check_hover_shift.py` 把这条钉成可失败的检查——它先
扫 CSSOM 里所有 `:hover` 规则，逮出任何改「在流内布局属性」（高度 / 边距 / 内外距…）的，
再真机 hover 视频行与章节行、比对整屏坐标。以后谁再写一版「悬停长高」的展开，门禁当场红。

### Z-Library 取书（后端 `zlib_client.py` 421 行 + 前端搜书页右栏 + 设置项）

定位是**第二条取书通路**：微信读书是「取回自己有权读的书」，Z-Library 是「直接下一份
EPUB / PDF 落进本地书架」。两者逻辑不同，所以是并排的两栏，不是合并的一栏。

- **走安卓 App 那套 eAPI**：登录用邮箱密码换回一对 `remix_userid` / `remix_userkey`
  令牌，之后每个请求把这对值当 cookie 带上；搜索、详情、取直链都是它的固定端点。照端点
  数出来，只用标准库 `urllib`，不引第三方包（`zlib_client.py` 开头写了为什么，也写了
  「为什么文件名是 `zlib_client.py` 而不是 `zlib.py`」——标准库已有 `zlib`，抢不过它）。
- **代理复用平台那一套**：环境里显式给的代理优先，否则读系统设置并**探一下端口通不通**，
  探通了才挂。探不通就当直连——本来就在墙外或局域网里跑的机器不需要它，硬塞一个死地址
  反而把能成的直连也拖垮。socks 代理不带 PySocks 走不通，同样跳过。
- **凭据只落令牌**：`DATA_DIR/zlib.json`（权限 600）里只有 remix 令牌与账号名，
  **不存密码**（密码在登录那一次请求里用完即弃）；界面回显只给 uid / key 的后四位。
  默认域名 `DEFAULT_DOMAIN = "1lib.sk"`，可在设置里换当前可用的镜像。
- **只收 EPUB / PDF**（`KEEP_EXT`）：mobi / azw3 收进来阅读器打不开，宁可不列下载钮。
- **下载直落本地书架**：`zlib.download()` 拿到字节后交给 `book_import.import_book()`，
  归进「本地书架」那一格（`book_layout.PREFIX_OF` 里登记了 `zlib_ → local`，不是新开一格），
  所以下完就能当普通书读、导 EPUB/PDF、走同一套笔记。这一路不带微信读书命名空间，
  也就不会去查官方接口。

### 每本书的阅读计划（`readplan.py` 391 行 + 详情页那块 + 阅读器底栏）

- **页数锚在正文，不锚在渲染**：界面上量不出「一页」这个物理单位，按渲染高度算页会随
  字号、窗口宽度天天变。所以每 `PAGE_CHARS = 1000` 个字符记作一页，跟显示设置无关，
  「还剩多少页」才是一句稳定的话，同一本书今天明天是同一个数。
- **进度取「只增不减」的高水位**：翻回去查个词，位置会往回走；照单全收的话「今天读了
  30 页」会缩成 8 页，打卡就假了。所以位置只用来算高水位，今日 / 本周的账记在跨过新高
  水位那一刻。
- **读完即留档**：读到那一刻把当时的目标、起止日期、共读了几天存进 `history`
  （`MAX_HISTORY = 40`），之后改新计划也冲不掉——「完成计划有完整记录」是这条的正题。
- **入口**：书籍详情页定 / 改 / 结束，就地重画；阅读器底栏实时显示「还剩 N 页」，
  读完变成「已读完全书」。
- 这一层是**纯函数**：进出都是 dict，不碰磁盘、不看时钟（now / today 由调用方传），
  所以能脱开服务单测；落盘与加锁在 `ui_server.py`（`load_plan` / `plan_do` / `plan_view`），
  账本在 `CACHE_DIR/readplan.json`。

### 砍掉主页 Agent 气泡与任务收纳栏

- **主页那颗常驻 Agent 气泡去掉了**（用户要求：主页不要对话入口）。划句问助手那条路仍在
  （划词小条的「问小助手」、阅读条那颗「问」），但它只由阅读器开出来，不再有主页的落脚点。
- **右下角的任务收纳栏（任务抽屉）撤掉了**：取书时的进度回到书卡封面那条进度条上，
  条子右侧多了一颗「**详情**」，点开就是原来抽屉里那份输出记录（`showTaskLog`）。
  任务数据本身没删（`tasks` / `taskOf` / `showTaskLog` 都还在），只是不再有常驻的落脚点。

### 侧边栏：从「悬停即切」改回「点一下才切」

上一轮那套「鼠标走到哪一格就自动切到哪一屏」，这一轮按用户要求砍掉了 hover 触发，只留
点击。原因是它在真机上反复表现为「手没动、页面自己换了一屏」（窄屏 reflow 会把另一格
挤到静止的指针底下，浏览器补发一个合成 `pointerover`，被当成真悬停）。砍掉之后，
`pointermove` 只剩两件事：边缘模式下的「指针离开内容区就收回」与长按拖拽换序。
长按门槛 `DRAG_HOLD = 400ms`，进态先抖一下，松手才把新顺序发回后端。

### 排版三修（竖排 / 溢出 / 规格）

- **竖排改横排**：按钮文字在窄容器里会一个一个字往下掉。修法是全站
  `button { white-space: nowrap }`，只有需要折行的章节标题那类再单独开回来。
- **文字不许戳出边框**：`flex: none` 的元素带着文字时不会缩，用的是 max-content 宽度，
  在窄栏里就戳出去了（写作屏左栏那句长说明在 214px 的稿子列里戳出过 82px）。修法是
  给这类定宽标签补 `min-width: 0` + `overflow: hidden`（需要就再加省略号 / 两行截断）。
- **外观缺省值只留一处真相**：同一样东西写在好几处、数值还对不上（毛玻璃模糊值 CSS 写
  24、设置弹窗却写死 26，JS 一跑滑杆就从 26 跳到 24）。`tests/check_spec.py` 只读源码，
  把「缺省值一处真相」与「按钮字一律 nowrap」两条按成会失败的断言。
- 顺带把流畅度与稳定性也钉进真机门禁（`check_hover_shift` / `check_theme` /
  `check_overflow` / `check_fluency` 四套），此后「顺」和「稳」都是可失败项，不再靠观感。

### 依赖同步

`requirements.txt` 与 `bootstrap.py` 的依赖门禁这一轮**没有改动**（Z-Library 与阅读计划
都只用标准库）。打包链与新模块进包清单照旧：`zlib_client.py` / `readplan.py` 已补进
`shell/build_macos.sh` 的 `APP_FILES`（脚本那条反向护栏——「根目录每个 `*.py` 必须都在
清单里」——本来就为这类漂移准备着）。

### 十处新增门禁（现在静态 26 + 真机 28，共 54 项）

| 套件 | 它守什么 | 为什么单开 |
|---|---|---|
| `tests/check_zlib.py`（静态） | 客户端本身：登录只存令牌不存密码、回显只给后四位、下载先登录、阅读器打不开的格式挡住、代理探测各情形 | 本机假 eAPI 顶替，一个真网请求都不发 |
| `tests/check_zlib_route.py`（静态） | 接口那一层：mode 认不认得、下载完有没有真走 `book_import` 落进书库、`walk()` 认不认得它是「本地书架」的书 | 假 eAPI 给的直链是一份现编的最小 EPUB，所以「下载 → 收书 → 上架」端到端跑过，全程离线 |
| `tests/check_plan.py`（静态） | 阅读计划纯函数：页数折算、只增不减、跨天 / 跨周记账、读完留档 | 纯逻辑，时间由调用方传，不用起浏览器 |
| `tests/check_spec.py`（静态） | 外观缺省值一处真相、按钮字一律 nowrap | 只读 `ui.html` 源码就能钉死的那一半规格毛病 |
| `tests/check_hover_shift.py`（真机） | 悬停不许顶动版面：先扫 CSSOM 逮改在流内布局的 `:hover`，再真机 hover 比对坐标 | 上一轮的病根在真机上看才清楚 |
| `tests/check_theme.py`（真机） | 切日 / 夜不许闪：换肤那一刻没有任何元素停在中间色 | 只有真机能掐两个中途采样点 |
| `tests/check_overflow.py`（真机） | 文字不许戳出边框：十二格 + 个人主界面 + 设置弹窗在三档宽度下各扫一遍 | 同一类写法全站都可能再犯 |
| `tests/check_fluency.py`（真机） | 顺与稳也要能失败：零报错、无长任务、连点 30 下不许有一屏卡在半透明 | 把当下的基线钉住 |
| `tests/check_zlib_ui.py`（真机） | 搜索页两栏：断点、就地登录、没 Key 时的说法、窄到两栏变上下排时不许再定高（定高会把下面那栏裁掉还滚不到） | 分栏只有真机点得出来 |
| `tests/check_plan_ui.py`（真机） | 详情页定 / 改 / 结束原地重画、底栏「还剩 N 页」跟着读到的位置走、读完变「已读完全书」并留档 | 计划另一半只有真机点得出来 |

## 2. 这一轮**没有**碰的东西

- 取书引擎、图片下载、阅读器正文、云同步（WebDAV / Microsoft Graph）、转写流水线没动。
- 画板 / 导图 / flomo 便签 / 写作平台 / 个人主界面（头像与两张热力图）的实现没动。
- MCP 工具数仍是 **56**（十一类），这一轮没加新工具；个数以 `tests/check_mcp_tools.py`
  现读 `tools/list` 为准。
- 没有新增第三方依赖，`requirements.txt` / `bootstrap.py` 都没碰。

## 3. 还没验过的（诚实清单）

- **Z-Library 的 eAPI 是照现成文档点出来的**，没对具体账号逐一联调；对方的域名与端点
  随时可能改，改版会表现为「搜不到 / 下不动」而不是报错。
- **Z-Library 的搜索与下载走本机代理**，代理不通时如实报「多半是代理」；直连（墙外
  机器）这条路径没有实测过。
- **下载成功率不做保证**：受账号额度、格式、镜像可用性影响；界面只是不显示「今日还能下
  几本」那一句（问不到就回 None）。
- **阅读计划的页数与真实「屏幕页」不是一个单位**（一页 = 1000 字），它稳定、能跨设备
  对账，但不等于翻了多少屏。
- **换肤、悬停、溢出、分栏这几条真机套件只在 Chromium 上验过**；Safari 没实测。
- **搜索页两栏的断点行为**只对着沙盒服务验过，没在真装过 `.app` 的机器上走一遍。
- **Windows 分支没端到端跑过**：本机只有 macOS。

## 4. 接手后先做的三件事

1. `bash tests/run_all.sh` 跑一遍全绿（现在是 **54 项**：静态 26 + 真机 28），确认环境与基线。
   改前端只需重启浏览器（`ui.html` 每次 GET 都重读）；**改后端必须换进程**（1.0.3 那轮的
   横幅就是为这件事存在的）。**跑真机套件时别同时改 `ui.html`——真机套件从磁盘现读
   `ui.html`，边跑边改会读到半份。**
2. 读 `ui_server.py` 的 `NAV_ITEMS` / `nav_view` 与 `ui.html` 里侧边栏那几段监听的 why
   注释。新增导航入口只改后端那张表、不要再在页面里手抄一份；**切页只许认点击，
   不要再挂 hover 触发**（这一轮刚砍掉）。
3. 新增任何界面调用的 `/api/...`，先补后端路由再写前端；`tests/check_route_pair.py` 会在静态门
   里拦住反过来的做法。真机套件一律通过 `bash tests/run_all.sh` 跑（它起沙盒并把地址传进去）。

## 5. 已知的坑（都踩过，写下来省下一次）

| 症状 | 根因 | 解法 |
|---|---|---|
| 鼠标顺着一列划过去，整栏都在跳 | 悬停展开动作行用的是「改高度」，把该行撑高、把后面每一行都推下去 | 悬停只改颜色 / 亮度，显隐用 `pointer-events` 不用高度；`check_hover_shift.py` 扫 CSSOM 拦下 |
| 切日 / 夜那一下全屏闪一下 | 每个组件各带各的补间时长，主题变量一跳，它们各按各的节奏从旧色补到新色，中间有「混色帧」 | 换肤那一帧给 `<html>` 挂 `.theme-switching`，一次性压平所有过渡；`check_theme.py` 掐中途采样点 |
| 窄栏里文字杵成一条竖线 | 按钮没 `nowrap`，一个字一个字换行 | 全站 `button { white-space: nowrap }`，要折行的章节标题单独开回来；`check_spec.py` 钉住 |
| 文字戳出边框、压进旁边那一栏 | `flex: none` 的元素带文字时用 max-content 宽、不会缩 | 定宽标签补 `min-width: 0` + `overflow: hidden`（加省略号 / 两行截断） |
| 滑杆一碰就从 26 跳到 24 | 同一个缺省值写在两处、数值还对不上 | 外观缺省值只留一处真相；`check_spec.py` 静态拦 |
| 手没动，页面自己换了一屏 | 窄屏 reflow 把另一格推到静止指针底下，浏览器补发合成的 `pointerover`，被当成真悬停 | 砍掉 hover 触发的切页，只留点击（这一轮）；切页监听不再挂 `pointermove` 之外的东西 |
| 取书时找不到输出记录 | 右下角任务抽屉撤了 | 书卡封面进度条右侧那颗「详情」点开就是那份记录；任务数据（`tasks` / `showTaskLog`）没删 |
| Z-Library 搜不到 / 下不动 | 域名被换、或代理没开 | 设置 → Z-Library 里换镜像域名；连不上时那句人话会点「多半是代理」 |
| 从浏览器 cookie 抄令牌「登录成功」却下不动 | 只存了令牌没校验 | `login_with_token` 先用令牌问一次 profile，问得到才存 |
| 装好的 `.app` 一进写作屏就崩 | `build_macos.sh` 的 APP_FILES 写死了旧清单，新模块没进包 | 新模块补进 APP_FILES；脚本的反向护栏本来就该拦住这类漂移（1.0.5 那轮） |
| 新入口对老用户凭空消失 | 导航名册改成后端存顺序后，老用户存的顺序表里没有新 id，被当「不认识」丢掉 | `nav_view()` 把存的顺序里缺的 id 补在末尾（1.0.5 那轮） |
| 点新功能只说「本机服务没在跑」，而服务活得好好的 | 界面把 404 与连不上揉成一句；真因是端口上挂着旧代码的进程 | `gzApi` 四类失败各说各的话 + 横幅写明两边版本 + `port_verdict` 判动作（1.0.3 那轮） |
| 手动跑一份真机套件，把用户正在用的实例接管了 | `need_base()` 不给参数就缺省挂 8770，而 8770 正是用户那台归藏 | `need_base()` 现在没地址**直接退出**并说清怎么指沙盒；真机套件一律走 `bash tests/run_all.sh`（1.0.3 那轮） |
| 整轮门禁偶发一个红，单独跑必绿 | 撞的是负载下的时序 | 复现要看负载；固定摆出断言而不是靠运气重跑 |
| 撤销点下去，那道线过一会儿又消失 | 存盘回执是「出发那一刻」的快照，`ntSave` 无条件拿它覆盖本地 doc | 每次 `ntTouch` 记 `NT.rev`；回执只在 `rev` 没动时才认（1.0.2/1.0.3 那轮） |
| flomo 重复导入出现「同一条两个 id」 | id 是 `sha1("时间\|正文")`，正文动一个字就成了另一条 | 存储里正文原样不动，标签与格式只在**交付时**清洗（1.0.1 那轮） |
| dmg 打完了在仓库里找不到 | `make_dmg.sh` 不传参数默认丢桌面 | `bash shell/make_dmg.sh 安装包`（`开发规范.md` §8 就是这么写的） |
| 新增 `const st` 直接语法错 | 同一函数作用域里 `st` 已被「语音识别」占用 | 换名；inline JS 门禁当场抓出来 |
