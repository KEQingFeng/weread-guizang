归藏 1.0.0 · 首次打开必读
==================================================

一、需要什么
  · macOS 13 或更高
  · 一个微信读书账号（用来扫码登录）
  · 网络。第一次打开要下载 Playwright 的 Chromium，约 370MB ——
    那是「取书」时翻页取正文用的浏览器。
  · 如果这台机器上没有任何 Python，先去 python.org/downloads 装一个
    3.9 以上的官方版本。装完不用重启，回来接着点就行。

二、第一次打开怎么开
  这个应用没有买苹果的开发者签名，macOS 会拦一下。做法是：
    · 把「归藏」拖进「应用程序」文件夹
    · 在它上面按右键 → 打开 → 弹窗里再点一次「打开」
  只需要这一次，之后双击就正常进。

  要是提示「已损坏，无法打开」（多见于用浏览器下载之后解压的情况），
  那不是文件坏了，是没有签名时 macOS 的默认说法。三种办法任选：
    · 打开「终端」，粘这一行回车，把下载隔离标记去掉：
        xattr -dr com.apple.quarantine /Applications/归藏.app
      （装到别处的把路径换成实际位置；提示 Operation not permitted 就在
       最前面加 sudo，会要你输开机密码）
    · 或者 系统设置 → 隐私与安全性 → 下滚到「安全性」，找到刚被拦下的
      那一条，点「仍要打开」
    · 用 Safari 下载的，多半不会触发这一条

三、第一次打开会发生什么
  窗口里是一个「我思故我在」按钮。点它，它会按顺序把缺的东西补齐：
    1. 建虚拟环境（装的东西全落在这个应用自己的数据目录里，不动系统 Python）
    2. 装 Python 依赖（playwright、genanki）
    3. 下载 Chromium
    4. 弹出一个窗口，用微信扫码登录
  四步都成了会自己淡出，进到书库界面。之后每次打开直接进。

  中途卡住多半是网络。确认代理软件开着「系统代理」，再点一次 ——
  它会接着从断掉的地方装，不会从头来。

四、东西存在哪
  ~/Library/Application Support/归藏/
    output/   取回来的书（逐章 Markdown + 图片 + 合并稿）
    cache/    登录态、书架标签、封面、壁纸
  应用本体里不含任何个人数据。

五、这份包只能在 macOS 上跑
  Windows 和 Linux 要另外构建，见仓库里的 部署说明.md。
