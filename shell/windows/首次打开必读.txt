归藏 1.0.8 · 首次打开必读（Windows）
==================================================

一、需要什么
  · Windows 10 或更高（64 位）
  · 一个微信读书账号（用来扫码登录）
  · 网络。第一次打开要装依赖，还要下载 Playwright 的 Chromium，约 370MB ——
    那是「取书」时翻页取正文用的浏览器。
  · Python 3.10 或更新版本。去 python.org/downloads 装官方版，安装界面
    第一步勾上 "Add python.exe to PATH"，装完不用重启。
    别用 Microsoft Store 里那个 python —— 那是占位程序，脚本会认出来跳过。

二、怎么装（两步）
  1. 把压缩包完整解压到一个文件夹。别在压缩包窗口里直接双击，那样会缺文件。
  2. 双击「安装归藏.bat」。
     它把程序复制到你的用户文件夹下的「归藏」（%USERPROFILE%\归藏），
     再在桌面放一个「归藏」快捷方式。以后从桌面那个进就行。

  不想装也行：直接双击「启动归藏.bat」就地跑，
  程序和数据都留在解压出来的那个文件夹里。

三、第一次打开会发生什么
  会出现一个黑窗口，按顺序把缺的东西补齐：
    1. 建虚拟环境（.venv，只在程序自己的目录里，不动系统 Python）
    2. 装 Python 依赖（playwright、genanki、pypdf、feedparser、yt-dlp）
    3. 下载 Chromium（约 370MB，慢的话先给终端挂上代理）
  装完会自动打开 http://127.0.0.1:8770 的界面，第一次要扫码登录微信读书。

  那个黑窗口别关 —— 它是后端服务，关了界面就没了；要停就关它。

  Windows 会弹「Windows 已保护你的电脑」（SmartScreen），因为这份程序没有买
  代码签名证书。点「更多信息」→「仍要运行」，只需要这一次。

四、东西存在哪
  装到 %USERPROFILE%\归藏 的话：
    %USERPROFILE%\归藏\output\   取回来的书、导入的书、剪藏、视频笔记
    %USERPROFILE%\归藏\cache\    登录态、书架标签、封面、壁纸、下载暂存
  就地跑的话，上面这两个目录就在解压出来的文件夹里。
  换端口：先 set GUIZANG_PORT=8899 再双击启动脚本（8770 被别的程序占着时用得上）。

五、几件如实要说的事
  · 这份包没在 Windows 上端到端跑过 —— 打包是在 macOS 上做的。安装脚本、
    启动脚本和跨平台那几处（platform_compat.py）都按 Windows 的规矩写，
    但没实测。
  · 视频转写走的是云端接口，需要你自己在设置里填一个兼容 OpenAI 的地址、
    Key 和模型名；本机不用装额外引擎。
  · ffmpeg 归藏不自带。视频转笔记要合并音视频时会用到它：把 ffmpeg 放进
    PATH，或直接丢在程序目录里。
  · 「安娜的档案」那个内置浏览器窗口在 Windows 上也没实测过。

六、出问题先看哪里
  · 黑窗口里的最后几行报错，通常直接说明了原因。
  · 报「没找到 Python」：装一个 3.10+ 并勾上 Add python.exe to PATH，再重新双击。
  · 卡在下载：多半是网络。挂上代理再双击一次，会从断掉的地方接着装。
