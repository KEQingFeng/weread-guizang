# 四段式填写样例

用《原子习惯》演示一遍四段式的形状和长度感。**内容仅用于演示格式，不是这本书的正式速通**；真正交付时按 SKILL.md 的规则读原书、标出处。示例里也遵守了禁用句式规则，可以拿来对照语气。

---

## 第 1 段 · 前导地图

**一句话主线**
一个人怎么把自己改造成想成为的那种人——靠的不是意志力，是环境和重复的工程设计。

**骨架**

```
习惯的底层机制
 └─ 身份 → 行为：改变从「我是谁」开始，不从「我要什么」开始
 └─ 1% 复利：每天好一点，一年后是 37 倍；差一点，是 0.03
 └─ 潜能蓄积期：结果滞后于努力，大部分人在突破前放弃
      ↓
四大定律（一个习惯的完整循环）
 ├─ 提示 → 让它显而易见（环境设计、习惯叠加、执行意图）
 ├─ 渴望 → 让它有吸引力（诱惑捆绑、圈子归属）
 ├─ 反应 → 让它简便易行（两分钟法则、减少摩擦）
 └─ 奖赏 → 让它令人满足（即时反馈、习惯追踪、不破两次）
      ↓
把定律反过来用：戒掉坏习惯
 └─ 看不见 / 没吸引力 / 难施行 / 令人厌恶
      ↓
边界
 └─ 天赋上限、领域选择、习惯与技能的接力
```

**概念坐标**

| 概念 | 落在哪 | 连到谁 |
|---|---|---|
| 身份认同 | 底层机制 | 所有四大定律的落点 |
| 潜能蓄积期 | 底层机制 | 解释「为什么坚持没结果」 |
| 习惯叠加 | 提示 | 依赖已有习惯当触发器 |
| 两分钟法则 | 反应 | 对抗启动阻力 |
| 不破两次 | 奖赏 | 防止单次失误变长期中断 |

**怎么读 + 读完的判据**

主干是前三章（机制）和第 4–7 章（四大定律），这七章占了全书 80% 的价值。后半本（第 8–20 章）是定律的展开和案例，可以按需跳读——第 11 章（基因与领域）值得单读，其余是可以扫过去的应用层。

读完你应该能：① 拿任何一个想养成的习惯，拆出它的提示—渴望—反应—奖赏四环，指出卡在哪；② 给一个明确的坏习惯，说出对应的反用法；③ 用习惯叠加 + 两分钟法则写出一条今天就能执行的行动。

## 第 2 段 · 核心讲义

### 块一 · 改变从身份开始 ⭐

**核心命题**：习惯的持久度取决于它长在哪个身份上；基于结果的习惯会耗尽，基于身份的习惯会自己续上。

**怎么推的**：作者把改变分三层——结果、过程、身份。大多数人从结果出发（我想瘦十斤），于是每次行动都在跟自己的现状较劲。反过来，先定下「我是一个每天训练的人」，再让行为去匹配这个身份，行为就变成了自我证明，而不是自我强迫。每一次行动都是在给「我想成为的那种人」投一票，票数攒够了，身份就换了。

**书里的例子**：作者举了两个拒绝香烟的人，同样递烟，一个说「不用了，我正在戒烟」，另一个说「不用了，我不抽烟」——第二个已经把自己重新定义过了。

**容易搞错**：身份不是喊口号喊出来的。先宣称身份再等行为跟上，只会变成自我感动。顺序是反的：小行为 → 证据 → 身份更新。两分钟法则就是给身份投票的最小单位。

**【动手】**：写下你想成为的那种人的一句身份陈述（「我是一个 ___ 的人」），然后找一件 2 分钟内能做完、符合这个身份的小事，今天就做一次。15 分钟，标准是写完的那句话让你有点不好意思说出口——太容易的话说明没写到真处。

### 块二 · 四大定律（略）

## 第 3 段 · 全书串讲

这本书真正在做的事，是把你对习惯的全部直觉翻过来一次。

我们默认的想法是：想改行为，得靠动力和意志力。动力来了就干，动力没了就断。作者说这条路的失败率高得离谱，原因在于你把它设计成了一场跟自己的拔河——每天都要重新决定一次「要不要做」。

他换的方式是：把决定权从当场的意志，挪到事先的环境和流程里。你想早起，就别在早上做决定，在前一晚把闹钟放到房间另一头。你想读书，就别指望读书的念头自己冒出来，把书摊在沙发上、手机留在卧室。（[示例缩略：原书这个部分用了几章展开环境设计和习惯叠加的具体做法]）

四大定律其实就是把「一个习惯能自动运转需要什么」拆成四步来检查……（后续一路讲到反用法、潜能蓄积期的心理学、以及为什么「不破两次」比「连续一百天」更管用）

【注：实际交付时这一段写成 800–1500 字连贯叙述，不分小标题，不复制讲义措辞。样例只保留开头和结构提示。】

## 第 4 段 · 带走

**一页速记**

1. 改变从身份开始，身份从小行为攒出来。
2. 每天 1%，一年 37 倍；半途没结果，是潜能蓄积期。
3. 习惯四环：提示 → 渴望 → 反应 → 奖赏。
4. 想养成：显而易见 + 有吸引力 + 简便易行 + 令人满足。
5. 想戒掉：反过来用同四条。
6. 习惯叠加 = 拿已有习惯当扳机。
7. 两分钟法则：把启动成本砍到不能再砍。
8. 环境比意志力可靠，先把摩擦改掉。
9. 追踪是有用的，但连着断两次才是失败线。
10. 天赋决定上限，习惯决定你走到上限的哪一段。

**行动清单**

- **今天**：写一句身份陈述，配一个两分钟内能做的动作，做掉它。（15 分钟）
- **这周**：挑一个反复失败的习惯，找出它卡在四环里的哪一环，只改那一环，连续执行五天。（每天 5 分钟）
- **用完之后**：把你手上一个拖着没做的项目，改写成一条「在我 [已有的日常动作] 之后，我会 [这个项目的最小一步两分钟版本]」的习惯叠加句，挂在明天的固定时段上。（20 分钟）
