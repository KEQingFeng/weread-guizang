玻璃

控制玻璃面板的透明度。调低更通透，可看清壁纸；调高更实，文字更易读。写作台、笔记纸与正文纸面为固定实心纸，不受此设置影响。

侧边栏
显示方式
常驻：侧边栏固定占用页面左侧。靠左缘滑出：侧边栏收起，页面占满宽度；指针移至窗口左缘时滑出，移开后自动收起。
入口显隐
取消勾选的入口不会出现在侧边栏与主页中。至少需保留一个入口，否则没有可显示的内容。此处顺序即侧边栏当前顺序。
排序
在侧边栏按住某个入口约 0.4 秒，图标轻微放大并进入拖动状态；拖至目标位置后松开，顺序保存在本机。短按仍为切换页面。

维护
组件 —
卸载的是为运行而安装的组件：虚拟环境（依赖安装在其中）、下载的 ffmpeg 以及取书所用的 Chromium。卸载后如需继续使用， 在「账号」页点击「修复」即可重新安装，无需重装整个软件。
本地数据 —
清除的内容包括：登录状态、书架清单、设置、阅读时长、 笔记索引、订阅条目、剪藏、封面与下载中间缓存。书籍文件不会被删除， 它们位于「文档 / 归藏」目录中。软件本体（.app）不在清除范围内，卸载时直接拖入废纸篓即可。
归藏 —
将微信读书面向 AI Agent 的官方接口，还原为本机可操作的图形界面：官方开放的能力做成界面，官方未开放的能力自行补齐。服务仅监听 127.0.0.1，不经过第三方服务器。
它能做什么
取书 通过 hook 阅读器画布获取正文，插图按阅读顺序交错插入；逐章写入磁盘，中断后可续取。
看书 书架、书城搜索、书籍详情、阅读统计与推荐，无需打开网页版即可在本地查看。
用笔记 全部划线建立索引后支持全文检索，随机漫步回顾，可导出为 Anki 或直接导入 flomo。
接 Agent 提供 MCP 工具，长任务不阻塞；服务未启动时由适配器自动启动。

书、图片、虚拟环境与浏览器配置均在此目录中。迁移到其他机器时，复制整个目录即可继续使用。
